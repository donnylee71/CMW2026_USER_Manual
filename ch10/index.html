    Chapter 10. Design Guide¶

    이 장은 모노블록 유전체 필터(Monoblock Dielectric Filter) 의 실제 설계 및 제작 가이드입니다. Partron RF Solution Team의 축적된 노하우를 바탕으로, 스펙 분석 → 기초 계산 → 구조 선정 → 자재 검토 → 단품 설계 → DPX 설계 → 완제품 검토 의 전체 흐름을 상세히 다룹니다.

    CONFIDENTIAL

    이 문서는 Partron 내부 기밀입니다. 외부 유출을 금합니다.

    10.1 유전체 필터/DPX 설계 전체 흐름¶

    유전체 필터 설계는 6단계로 진행됩니다.

    1
    Spec 분석
    ➔
    2
    기초 계산
    ➔
    3
    구조 선정
    ➔
    4DR
    자재 검토
    ➔
    5
    단품 필터 설계
    ➔
    6

    그림 10-1: 유전체 필터/DPX 설계 전체 흐름 (6단계)

    단계 내용 주요 활동
    1. Spec 분석 전기적/물리적 규격, 신뢰성 규격 확인 Compliance Matrix 작성
    2. 기초 계산 IDEAL 구조 확인, 기개발 유사 사양 확인 예상 Qu, 필터 구조, 세라믹/기타 자재 검토
    3. 구조 선정 소체, 케이스, PCB 선정 금형 보유 여부 확인, 신규 설계 여부 결정
    4. 자재 검토 (DR) 부품·자재 검증 및 발주 신규 자재 설계 후 발주, EM 시뮬레이션
    5. 단품 필터 설계 기존 금형 사용 또는 신규 금형 설계 INOUT/Coupling/TZ 패턴 설계
    6. 완제품 검토 전기적/물리적/온도 특성 검토 최종 양산성 확인

    리뷰 포인트

    • 온도 변화량 감안한 전기적 스펙 마진
    • 공정 고려한 조립 공차
    • 신뢰성 고려한 자재 설계
    • 고객 요구사항에 대한 만족도 리뷰

    10.2 1단계: Spec 분석¶

    10.2.1 확인 항목¶

    구분 확인 내용
    Electrical 일반적인 규격 외의 특이사항 확인
    Mechanical 고객 요구 상세 디멘전 (도면 형태로 추가)
    Reliability 내부적으로 검토 불가한 규격 확인

    10.2.2 Compliance Matrix 작성¶

    고객 요구사항을 한 장의 Compliance Matrix 로 정리하여, 모든 스펙을 빠짐없이 검토합니다.

    10.3 2단계: 기초 계산¶

    10.3.1 IDEAL 구조 확인¶

    그림 10-2: CMW2026의 Synthesize 결과 (8-Pole, R/L=20dB, Qu=370)

    1. ATT 요구 규격에 따라 필터 차수(N), 전송 영점(TZ) 결정
    2. IL 요구 규격 만족을 위한 공진기 Qu 값 계산
    3. Qu 값을 만족하는 유전체 블록(사이즈, 유전율) 결정

    CMW2026 활용

    위 과정은 CMW2026의 Synthesize 모드에서 직접 수행할 수 있습니다. - N, RL, Qu, F_Start, F_Stop 입력 → Goals 설정 → Auto Tuning - TZ는 Synthesize TZ 테이블에서 추가/조정

    10.3.2 기개발 유사 사양 확인¶

    • 기개발 스펙 중 중심주파수, BW가 유사한 품목 확인
    • 유사 규격이 있으면 참고하여 규격 결정

    10.3.3 결정 전 유의사항¶

    • 무리한 요구 사양은 고객과 협의 후 진행
    • 생산성 및 온도 변화 감안하여 규격 마진 확보 필수

    10.4 3단계: 구조 선정¶

    10.4.1 기본 구조 (소체, CASE, PCB) 선정¶

    그림 10-3: 소체/CASE/PCB 조립 구조 및 SPACER

    1. 기초 계산에서 필터 차수 결정
    2. 적용 가능한 기보유 소체 금형 확인 → 미보유 시 신규 소체 설계
    3. 적용 가능한 기보유 CASE 금형 확인 → 미보유 시 신규 CASE 설계
    4. 적용 가능한 기보유 PCB 확인 → 미보유 시 신규 설계
    5. SPACER 적용 유무 확인

    10.5 4단계: 자재 검토¶

    10.5.1 신규 소체 설계 가이드¶

    그림 10-4: 신규 소체 설계 기준 (홀 지름, 살 간격, R, 연마 길이)

    항목 기준
    공진홀 최소 지름 0.6 mm
    홀 사이 살 최소 간격 0.8 mm
    외곽 테두리 자연 R 0.2 적용
    바닥면 연마 길이 0.15 ~ 0.2 mm
    외곽 사이즈 패턴 설계 감안하여 적용

    연태 소체 성형 기준표

    기보유 금형 소체 제작 시 연태 소체 성형 기준표를 따릅니다. 파우더에 따라 성형 사이즈가 다를 수 있으므로 주의하세요.

    10.5.2 신규 CASE 설계 가이드¶

    그림 10-5: 신규 CASE 설계 기준 (튜닝창, 엣지 브릿지)

    항목 기준
    ① 모서리 R 튜닝창 끝부분 ~ 케이스 끝까지 거리
    ② 튜닝창 너비 최소 1.5 이상
    ③ 창 사이 살너비 최소 0.7 이상
    ④ 윗면 창 길이 케이스 조립 간격보다 0.2 크게
    ⑤ 엣지 브릿지 살너비 최소 0.5 이상
    ⑥ (Huawei) L 소체의 75% 이상 규격 (가능한 짧게 설계)

    재질 및 도금:

    고객 도금 사양
    Huawei Ag 1.0um min / 하지 Ni 0.5um min
    삼성네트웍 Ni 1.0um min
    그 외 Sn 3.0um min / 하지 Ni 0.5um min
    • 케이스 재질: 일반적으로 인정동 (상황에 따라 SUS430)
    • 케이스 두께: 일반적으로 0.2T (특수한 경우 0.15T 또는 0.3T)
    • 제작 방식: 최근에는 선타발 후도금 방식(릴금형) 주로 채택

    10.5.3 신규 PCB 설계 가이드¶

    그림 10-6: 신규 PCB 설계 기준 (OUTLINE, CU층, VIA)

    공통 적용 사항:

    • 신뢰성(열충격) 확보를 고려한 솔더 랜드 설계
    • 단자 주위를 감싸는 형태로 설계하되 구획을 나눠서 설계
    • 동노출 방지: OUTLINE보다 CU층을 0.2 안쪽으로 설계
    • 과도한 VIA는 단가 상승 원인 → 불필요한 VIA 삭제
    • 필터 단자 주위 전송선로 위주로 VIA 총총(약 1mm 간격) 설계
    • VIA 최소 지름: 0.25 (티에스 기준), 일반적으로 0.3 이상
    • SILK 글자 크기: 최소 0.8 (1.0 권장)
    • MLCC LAND: 제조사 제공 Recommend 적용, 반드시 양쪽 대칭 설계
    • AIR COIL LAND: 코일 LEAD선이 충분히 솔더링 될 수 있는 영역 확보

    PCB 두께 선정:

    • 기본적으로 고객사 요청사항에 준함
    • FR4 기준 0.8T: 동박 포함 두께, 최종 가공 후 0.9T
    • 0.6T 이하: 동박 미포함 두께, 최종 가공 후 0.7T + 동박 두께
    • SPACER 적용 시 해당 두께 감안하여 원판 두께 선정

    VIA 솔더 흐름 방지:

    • VIA는 솔더 오픈 영역에서 최소 0.3mm 띄워서 설계
    • 솔더 Top/Bottom이 공통으로 열린 공간에는 VIA 설계 금지

    ARRAY 브리지 설계:

    • 라우팅 시 소체 손상 방지를 위해 소체 최외곽에서 최소 1mm 떨어진 지점에 브리지 설계
    • 개발 샘플 진행 시 수작업을 위해 미싱홀 또는 V-CUT 적용 필

    Huawei 적용 사항:

    • Halogen Free 기판 적용 필수
    • 반스루홀 도금 100% 적용
    • 단자 사이즈 관리 기준 명시할 것

    10.6 5단계: 단품 필터 설계¶

    10.6.1 설계 결정 인자¶

    그림 10-7: 필터 설계 결정 인자 (입출력 Qe, 커플링, 전송 영점)

    인자 결정 사항
    입출력 Qe Open 구조, Short 구조, Spurline 적용 유무 결정
    커플링 구성 Capacitive / Inductive 커플링 배치 결정
    전송 영점 구성 Cross Coupling 구조 (너치바, 홀너치) 결정

    10.6.2 인아웃 패턴 설계¶

    그림 10-8: 인아웃 패턴 3종 (Open, Short, Spurline)

    구조 특징 적용
    Open 구조 가장 일반적인 구조 대부분의 필터
    Short 구조 Open 구조에서 구현하기 힘든 Wide BW에 적용 광대역 필터
    Spurline 적용 하모닉 저지 성능이 필요한 경우 적용 하모닉 억제 필요 시

    설계 절차:

    1. 커플필 프로그램 또는 회로 시뮬레이션을 통해 이상적인 초단 GD peak 계산
    2. 초단 공진기를 제외한 다른 공진기는 Short 처리
    3. 이상적인 GD peak 값이 나오도록 인아웃 크기 조절

    그림 10-9: 인아웃 패턴 설계 예시 및 GD peak

    10.6.3 커플링 패턴 설계¶

    그림 10-10: 커플링 패턴 4종 (L 커플링 2종, C 커플링 2종)

    패턴 특징
    ① L 커플링 기본 BAR 길이로 커플링 크기 조절
    ② L 커플링 (하모닉 개선) 하모닉 특성 개선 효과, BW가 맞지 않으면 적용 어려움
    ③ C 커플링 기본 패턴 간 GAP 조절로 커플링 크기 조절
    ④ C 커플링 (Wideband) Wideband 구현 시 커플링 값 극대화

    커플링 선택 가이드

    • L 커플링 → HIGH 밴드 ATT 성능 강화에 유리
    • C 커플링 → LOW 밴드 ATT 성능 강화에 유리

    10.6.4 전송 영점(TZ) 설계 패턴¶

    양단 너치 구현 BAR 패턴 (2종)

    그림 10-11: 양단 너치 구현 BAR 패턴 2종

    패턴 특징
    ① 대칭형 패턴 성능 최적화 편리하지만 양단 너치 밸런스 조절 불가
    ② 비대칭 패턴 최적화 난이도는 높으나 양단 너치 밸런스 조절 가능

    단방향 너치 구현 BAR 패턴 (4종)

    그림 10-12: 단방향 너치 BAR 패턴 4종

    패턴 특징
    ① 하단 주파수 TZ 길이 조절로 비교적 너치 위치 조절 자유로움
    ② 상단 주파수 TZ 길이 조절로 비교적 너치 위치 조절 자유로움
    ③ 하단 주파수 TZ (INOUT 연결) 인아웃 패턴과 연결되어 컨트롤 난이도 중간
    ④ 상단 주파수 TZ (INOUT 연결) 인아웃 패턴과 연결되어 컨트롤 난이도 중간

    공진홀 튜닝형 너치 패턴 (2종)

    그림 10-13: 공진홀 튜닝형 너치 패턴 2종

    패턴 특징
    ① 하단 주파수 TZ 공진홀 튜닝으로 미세하게 TZ 위치 조절 가능
    ② 상단 주파수 TZ 공진홀 튜닝으로 미세하게 TZ 위치 조절 가능

    10.6.5 Full Model 3D 설계¶

    그림 10-14: Full Model 3D 설계 (Lumped Port 설정)

    절차:

    1. HFSS 또는 CST로 3D Full 모델링
    2. 계산된 GD peak가 나오도록 초단 INOUT 형상 설계
    3. 각 공진기에 Lumped Port 설정 후 sNp 파일 추출 (7-pole의 경우 S9P)

    그림 10-15: 회로 시뮬레이션으로 C값 최적화 후 3D 물리 변수로 변환

    회로 시뮬레이션 최적화:

    1. sNp 파일을 회로 시뮬레이션(예: ADS)으로 불러와 각 공진기에 C 연결
    2. 연결된 C를 튜닝하여 특성 최적화
    3. 최적화된 C값을 3D 물리 변수로 변환하여 시뮬레이션 반복

    CMW2026 활용

    3D Full Model에서 추출한 sNp 파일을 CMW2026의 Import s2p(오버레이 비교)로 불러와, 현재 매트릭스 파형과 비교할 수 있습니다.

    10.6.6 실제 제품 설계 예시¶

    그림 10-16: 실제 제품 설계 예시 (패턴별 TZ 형성)

    패턴 역할
    1번 패턴 HIGH 주파수 전송 영점 형성
    2번 패턴 LOW, HIGH 양단 전송 영점 형성
    3번 패턴 LOW 주파수 전송 영점 형성

    10.7 6단계: DPX 설계 이론¶

    10.7.1 DPX(듀플렉서) 기본 이론¶

    그림 10-17: DPX 기본 이론 (BPF+BPF, Smith Chart 위상 변환)

    • DPX = BPF + BPF
    • 서로 다른 대역의 BPF 2개를 선정하여 DPX 제작 시, 미스매칭에 의해 성능 구현이 안 됨
    • BPF의 스미스차트에서 상대 대역의 위치가 OPEN점에 위치하도록 위상 변환 설계
    • 단 필터 간 주파수가 가깝거나 BW가 넓은 경우 추가적인 필터 초단(ANT) 패턴 설계 변경이 필요

    10.7.2 DPX 설계 예시 (BPF+BPF 듀플렉서)¶

    그림 10-18: DPX 설계 예시 (BPF+BPF 듀플렉서, 매칭/위상천이)

    설계 절차:

    1. BPF2를 오픈시킨 후, BPF1에 적당한 L, C로 매칭하여 상대 대역을 OPEN점으로 이동 (이때 BPF1 대역은 50Ω 매칭)
    2. BPF1을 오픈시킨 후, BPF2에 적당한 L, C로 매칭하여 상대 대역을 OPEN점으로 이동 (이때 BPF2 대역은 50Ω 매칭)
    3. 각각의 매칭값을 찾은 후, 모든 소자를 연결하여 특성 확인 및 추가 미세 Lumped 값 튜닝
    4. Lumped 매칭으로 부족한 부분은 필터 패턴 추가 튜닝 최적화

    NOTE

    전송선로 이용 시 라인이 길어질 수 있어, Lumped LC 소자를 이용한 매칭이 일반적입니다.

    10.7.3 DPX 설계 예시 (Monoblock DPX)¶

    그림 10-19: Monoblock DPX 설계 예시 (RX/TX/ANT 패턴 통합)

    설계 절차:

    1. RX BPF 패턴 설계
    2. TX BPF 패턴 설계
    3. ANT 인아웃 패턴 및 공진기 설계 (계산값과 같은 딜레이가 나오도록 패턴 설계)
    4. 각각 설계된 패턴을 모두 합친 후 추가 최적화 진행

    10.9 8단계: 완제품 검토¶

    10.9.1 연마 과정 주의 사항¶

    그림 10-20: 연마 과정 주의 사항 (홀막힘, Ag 탈락, 소체 표면 파손)

    높이 연마 기준:

    • PAD 인쇄 두께, 솔더 조립 두께 감안하여 케이스 높이보다 0.03mm 짧게 연마
    • 홀이 막힌 소체는 내부 디핑 불량 확률이 높으므로 사용하지 않음
    • 연마 과정 중 발생한 Ag 탈락 및 소체 표면 파손 소체는 사용하지 않음
    • 소체 횡방향 확인하여 불록한 부분을 위로 가게 적재 후 연마 진행

    10.9.2 인쇄 및 Laser 주의 사항¶

    그림 10-21: 인쇄 스크린 도면 및 Laser 가공 도면

    • 인쇄 스크린 도면은 실제 패턴 사이즈와 동일하게 작성
    • 모서리 외곽으로 0.2mm 크게 도면 작성 필요
    • Laser 작업 시 실제 패턴보다 0.015mm 옵셋 설정 필요
    • 도면 대비 가공면이 크게, 패턴이 작게 형성됨
    • PAD면 Laser 가공 시 치수 확인 후 보정 필수
    • 패턴의 최소 Width: 0.2mm, Gap: 0.1mm 적용하여 설계
    • 좀 더 작게 설계할 경우 오픈 또는 쇼트 위험

    그림 10-22: 인쇄 불량 사례 (모서리 연결부, PORT 연결부, PORT GAP 미세 쇼트)

    인쇄 품질 관리:

    • 공판 인쇄 및 건조 후 표면 인쇄 상태 육안 확인 (Ag 탈락부위, 메쉬자국)
    • PAD-TOP 연결 모서리 부분이 인쇄 두께 취약 → 현미경 관리
    • 패턴 가공 후 PAD-TOP PORT 연결 부위 일치 여부 확인 필수
    • PAD-TOP 연결 모서리 PORT GAP 부분 미세 쇼트 제거 철저
    • 미세 쇼트 상태에서도 특성이 나올 수 있으므로, 쇼트 상태에서 최적화가 이루어지지 않도록 주의

    10.9.3 솔더 조립 주의 사항¶

    그림 10-23: 솔더 조립 불량 사례 (냉납, 솔더 필렛, 리칭)

    • 케이스 조립 시 고객사별 솔더 구분 적용
    • 삼성: 단양
    • Huawei: CVP-390
    • 그 외: OL-213
    • PCB 조립 시: OL-213 솔더 적용
    • 조립 후 냉납, 솔더 필렛 형성 유무, 리칭 여부 확인 필수
    • 조립 후 플럭스 세척 필수 진행 (초음파 세척 시 180초 이내, 장시간 진행 시 Ag 벗겨질 수 있음)

    10.9.4 튜닝 및 패턴 최적화¶

    그림 10-24: 튜닝 시 단선 위험 및 BURR로 인한 SHORT

    • 후면 패턴은 공진기 성능 저하 → 가능한 TOP면에서 패턴 최적화 진행
    • 부득이 후면 패턴 필요 시 바닥면에서 최소 0.5mm 이상 떨어지게 설계
    • 튜닝성을 고려하여 인접한 패턴을 가능한 피해서 설계
    • 패턴은 가능한 단순하게 설계하고, 튜닝을 위한 패턴을 필히 남겨 놓아야 함
    • 미세하고 복잡한 패턴 부위는 단선 및 쇼트 우려 → 가급적 튜닝 자재
    • 튜닝에 의한 Ag 밀림으로 인한 미세 BURR 제거 확인 필수 (고객사 유출 시 불량 발생 위험)
