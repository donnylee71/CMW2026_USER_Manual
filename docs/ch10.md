*그림 10-1: 유전체 필터/DPX 설계 전체 흐름 (6단계)*

| 단계 | 내용 | 주요 활동 |
|------|------|----------|
| **1. Spec 분석** | 전기적/물리적 규격, 신뢰성 규격 확인 | Compliance Matrix 작성 |
| **2. 기초 계산** | IDEAL 구조 확인, 기개발 유사 사양 확인 | 예상 Qu, 필터 구조, 세라믹/기타 자재 검토 |
| **3. 구조 선정** | 소체, 케이스, PCB 선정 | 금형 보유 여부 확인, 신규 설계 여부 결정 |
| **4. 자재 검토 (DR)** | 부품·자재 검증 및 발주 | 신규 자재 설계 후 발주, EM 시뮬레이션 |
| **5. 단품 필터 설계** | 기존 금형 사용 또는 신규 금형 설계 | INOUT/Coupling/TZ 패턴 설계 |
| **6. 완제품 검토** | 전기적/물리적/온도 특성 검토 | 최종 양산성 확인 |

!!! tip "리뷰 포인트"
    - 온도 변화량 감안한 전기적 스펙 마진
    - 공정 고려한 조립 공차
    - 신뢰성 고려한 자재 설계
    - 고객 요구사항에 대한 만족도 리뷰

## 10.2 1단계: Spec 분석

### 10.2.1 확인 항목

| 구분 | 확인 내용 |
|------|----------|
| **Electrical** | 일반적인 규격 외의 특이사항 확인 |
| **Mechanical** | 고객 요구 상세 디멘전 (도면 형태로 추가) |
| **Reliability** | 내부적으로 검토 불가한 규격 확인 |

### 10.2.2 Compliance Matrix 작성

고객 요구사항을 **한 장의 Compliance Matrix** 로 정리하여, 모든 스펙을 빠짐없이 검토합니다.

## 10.3 2단계: 기초 계산

### 10.3.1 IDEAL 구조 확인

<a href="../images/ch10/fig-10-02.png" target="_blank">
  <img src="../images/ch10/fig-10-02.png" alt="Ultra-Fast Realtime Response 및 필터 스펙 입력" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">

*그림 10-2: CMW2026의 Synthesize 결과 (8-Pole, R/L=20dB, Qu=370)*

1. **ATT 요구 규격**에 따라 필터 차수(N), 전송 영점(TZ) 결정
2. **IL 요구 규격** 만족을 위한 공진기 **Qu 값 계산**
3. Qu 값을 만족하는 **유전체 블록(사이즈, 유전율) 결정**

!!! note "CMW2026 활용"
    위 과정은 CMW2026의 **Synthesize 모드**에서 직접 수행할 수 있습니다.
    - `N`, `RL`, `Qu`, `F_Start`, `F_Stop` 입력 → **Goals** 설정 → **Auto Tuning**
    - TZ는 **Synthesize TZ 테이블**에서 추가/조정

### 10.3.2 기개발 유사 사양 확인

- 기개발 스펙 중 **중심주파수, BW가 유사한 품목** 확인
- 유사 규격이 있으면 참고하여 규격 결정

### 10.3.3 결정 전 유의사항

- **무리한 요구 사양**은 고객과 협의 후 진행
- **생산성 및 온도 변화** 감안하여 규격 마진 확보 필수

### 10.5.3 신규 PCB 설계 가이드

<a href="../images/ch10/fig-10-06.png" target="_blank">
  <img src="../images/ch10/fig-10-06.png" alt="신규 PCB 설계 기준" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-6: 신규 PCB 설계 기준 (OUTLINE, CU층, VIA)*

**공통 적용 사항**:

- 신뢰성(열충격) 확보를 고려한 **솔더 랜드 설계**
- 단자 주위를 감싸는 형태로 설계하되 **구획을 나눠서 설계**
- **동노출 방지**: OUTLINE보다 CU층을 0.2 안쪽으로 설계
- **과도한 VIA**는 단가 상승 원인 → 불필요한 VIA 삭제
- 필터 단자 주위 전송선로 위주로 **VIA 총총(약 1mm 간격)** 설계
- **VIA 최소 지름**: 0.25 (티에스 기준), 일반적으로 0.3 이상
- **SILK 글자 크기**: 최소 0.8 (1.0 권장)
- **MLCC LAND**: 제조사 제공 Recommend 적용, **반드시 양쪽 대칭 설계**
- **AIR COIL LAND**: 코일 LEAD선이 충분히 솔더링 될 수 있는 영역 확보

**PCB 두께 선정**:

- 기본적으로 **고객사 요청사항**에 준함
- FR4 기준 **0.8T**: 동박 포함 두께, 최종 가공 후 0.9T
- **0.6T 이하**: 동박 미포함 두께, 최종 가공 후 0.7T + 동박 두께
- **SPACER** 적용 시 해당 두께 감안하여 원판 두께 선정

**VIA 솔더 흐름 방지**:

- VIA는 솔더 오픈 영역에서 **최소 0.3mm** 띄워서 설계
- 솔더 Top/Bottom이 공통으로 열린 공간에는 **VIA 설계 금지**

**ARRAY 브리지 설계**:

- 라우팅 시 **소체 손상 방지**를 위해 소체 최외곽에서 **최소 1mm** 떨어진 지점에 브리지 설계
- 개발 샘플 진행 시 수작업을 위해 **미싱홀 또는 V-CUT** 적용 필

**Huawei 적용 사항**:

- **Halogen Free** 기판 적용 필수
- **반스루홀 도금 100%** 적용
- 단자 사이즈 관리 기준 명시할 것

*그림 10-8: 인아웃 패턴 3종 (Open, Short, Spurline)*

| 구조 | 특징 | 적용 |
|------|------|------|
| **Open 구조** | 가장 일반적인 구조 | 대부분의 필터 |
| **Short 구조** | Open 구조에서 구현하기 힘든 Wide BW에 적용 | 광대역 필터 |
| **Spurline 적용** | 하모닉 저지 성능이 필요한 경우 적용 | 하모닉 억제 필요 시 |

**설계 절차**:

2. 초단 공진기를 제외한 다른 공진기는 **Short 처리**
3. 이상적인 GD peak 값이 나오도록 **인아웃 크기 조절**

## 10.7 6단계: DPX 설계 이론

### 10.7.1 DPX(듀플렉서) 기본 이론

<a href="../images/ch10/fig-10-17.png" target="_blank">
  <img src="../images/ch10/fig-10-17.png" alt="DPX 기본 이론 (BPF+BPF)" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-17: DPX 기본 이론 (BPF+BPF, Smith Chart 위상 변환)*

- **DPX = BPF + BPF**
- 서로 다른 대역의 BPF 2개를 선정하여 DPX 제작 시, **미스매칭**에 의해 성능 구현이 안 됨
- BPF의 **스미스차트에서 상대 대역의 위치가 OPEN점**에 위치하도록 **위상 변환 설계**
- 단 필터 간 주파수가 가깝거나 BW가 넓은 경우 **추가적인 필터 초단(ANT) 패턴 설계 변경**이 필요

### 10.7.2 DPX 설계 예시 (BPF+BPF 듀플렉서)

<a href="../images/ch10/fig-10-18.png" target="_blank">
  <img src="../images/ch10/fig-10-18.png" alt="DPX 설계 예시 (BPF+BPF)" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-18: DPX 설계 예시 (BPF+BPF 듀플렉서, 매칭/위상천이)*

**설계 절차**:

1. **BPF2를 오픈**시킨 후, BPF1에 적당한 **L, C로 매칭**하여 상대 대역을 **OPEN점으로 이동**
   (이때 BPF1 대역은 50Ω 매칭)
2. **BPF1을 오픈**시킨 후, BPF2에 적당한 **L, C로 매칭**하여 상대 대역을 **OPEN점으로 이동**
   (이때 BPF2 대역은 50Ω 매칭)
3. 각각의 매칭값을 찾은 후, **모든 소자를 연결**하여 특성 확인 및 **추가 미세 Lumped 값 튜닝**
4. Lumped 매칭으로 부족한 부분은 **필터 패턴 추가 튜닝 최적화**

!!! note "NOTE"
    전송선로 이용 시 라인이 길어질 수 있어, **Lumped LC 소자**를 이용한 매칭이 일반적입니다.

### 10.7.3 DPX 설계 예시 (Monoblock DPX)

<a href="../images/ch10/fig-10-19.png" target="_blank">
  <img src="../images/ch10/fig-10-19.png" alt="Monoblock DPX 설계 예시" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-19: Monoblock DPX 설계 예시 (RX/TX/ANT 패턴 통합)*

**설계 절차**:

1. **RX BPF 패턴** 설계
2. **TX BPF 패턴** 설계
3. **ANT 인아웃 패턴 및 공진기** 설계
   (계산값과 같은 딜레이가 나오도록 패턴 설계)
4. 각각 설계된 패턴을 **모두 합친 후 추가 최적화** 진행

## 10.9 8단계: 완제품 검토

### 10.9.1 연마 과정 주의 사항

<a href="../images/ch10/fig-10-20.png" target="_blank">
  <img src="../images/ch10/fig-10-20.png" alt="연마 과정 주의 사항" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-20: 연마 과정 주의 사항 (홀막힘, Ag 탈락, 소체 표면 파손)*

**높이 연마 기준**:

- PAD 인쇄 두께, 솔더 조립 두께 감안하여 **케이스 높이보다 0.03mm 짧게** 연마
- **홀이 막힌 소체**는 내부 디핑 불량 확률이 높으므로 **사용하지 않음**
- 연마 과정 중 발생한 **Ag 탈락 및 소체 표면 파손** 소체는 **사용하지 않음**
- 소체 횡방향 확인하여 **불록한 부분을 위로 가게** 적재 후 연마 진행

### 10.9.2 인쇄 및 Laser 주의 사항

<a href="../images/ch10/fig-10-21.png" target="_blank">
  <img src="../images/ch10/fig-10-21.png" alt="인쇄 및 Laser 주의 사항" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-21: 인쇄 스크린 도면 및 Laser 가공 도면*

- 인쇄 스크린 도면은 **실제 패턴 사이즈와 동일**하게 작성
- 모서리 외곽으로 **0.2mm 크게** 도면 작성 필요
- Laser 작업 시 실제 패턴보다 **0.015mm 옵셋** 설정 필요
- 도면 대비 가공면이 크게, 패턴이 작게 형성됨
- **PAD면 Laser 가공 시 치수 확인 후 보정 필수**
- 패턴의 **최소 Width: 0.2mm, Gap: 0.1mm** 적용하여 설계
- 좀 더 작게 설계할 경우 **오픈 또는 쇼트 위험**

<a href="../images/ch10/fig-10-22.png" target="_blank">
  <img src="../images/ch10/fig-10-22.png" alt="인쇄 불량 사례" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-22: 인쇄 불량 사례 (모서리 연결부, PORT 연결부, PORT GAP 미세 쇼트)*

**인쇄 품질 관리**:

- 공판 인쇄 및 건조 후 **표면 인쇄 상태 육안 확인** (Ag 탈락부위, 메쉬자국)
- **PAD-TOP 연결 모서리** 부분이 인쇄 두께 취약 → **현미경 관리**
- 패턴 가공 후 **PAD-TOP PORT 연결 부위 일치 여부** 확인 필수
- **PAD-TOP 연결 모서리 PORT GAP 부분 미세 쇼트 제거** 철저
- 미세 쇼트 상태에서도 특성이 나올 수 있으므로, **쇼트 상태에서 최적화가 이루어지지 않도록 주의**

### 10.9.4 튜닝 및 패턴 최적화

<a href="../images/ch10/fig-10-24.png" target="_blank">
  <img src="../images/ch10/fig-10-24.png" alt="튜닝 및 패턴 최적화" style="max-width: 100%; height: auto; border: 1px solid #ddd; border-radius: 4px;">
</a>

*그림 10-24: 튜닝 시 단선 위험 및 BURR로 인한 SHORT*

- **후면 패턴**은 공진기 성능 저하 → 가능한 **TOP면에서 패턴 최적화** 진행
- 부득이 후면 패턴 필요 시 **바닥면에서 최소 0.5mm 이상** 떨어지게 설계
- 튜닝성을 고려하여 **인접한 패턴을 가능한 피해서** 설계
- 패턴은 가능한 **단순하게 설계**하고, **튜닝을 위한 패턴을 필히 남겨 놓아야** 함

- 튜닝에 의한 **Ag 밀림으로 인한 미세 BURR 제거** 확인 필수 (고객사 유출 시 불량 발생 위험)
