# Chapter 2. 설치 및 라이선스

CMW2026은 **Setup 설치 프로그램**으로만 실행할 수 있으며, **등록된 PC에서만** 동작합니다.

!!! warning "핵심 요약"
    - **Setup.exe 로 설치**해야 실행 가능 (실행 파일 복사만으로는 동작 안 함)
    - **등록된 PC 1대에서만** 실행 (라이선스 없으면 즉시 종료)

---

## 2.1 시스템 요구사항

| 항목 | 최소 | 권장 |
|------|------|------|
| OS | Windows 10 (64-bit) | Windows 11 |
| .NET Framework | 4.7.2 이상 | 4.8 이상 |
| RAM | 4 GB | 8 GB |
| 해상도 | 1280 × 800 | 1920 × 1080 |

---

## 2.2 설치 절차

1. **`Setup.exe` 실행** → 설치 마법사 진행
2. 설치 완료 후 **시작 메뉴**에 바로가기 생성
3. **`license.lic`** 파일을 **설치 폴더**에 복사
4. **시작 메뉴 → Coupling Matrix Wizard 2026** 실행

!!! tip "설치 폴더 확인 방법"
    시작 메뉴의 CMW2026 바로가기 → **우클릭 → 속성 → 파일 위치 열기**

!!! warning "포터블 미지원"
    실행 파일(.exe)만 복사하거나 ZIP 압축 해제만으로는 **실행되지 않습니다.** 반드시 Setup으로 설치하세요.

---

## 2.3 라이선스 정책

### 방식
- **하드웨어 핑거프린트 기반** (CPU ID + 메인보드 + MAC + 디스크 시리얼 조합)
- **PC 1대당 라이선스 1개** (PC 변경 시 재발급 필요)
- **`license.lic`** 파일이 설치 폴더에 있어야 인증 성공

### 인증 절차
1. `license.lic` 파일 존재 확인
2. 현재 PC 하드웨어 핑거프린트 계산
3. 등록된 정보와 비교 → **일치 시 정상 실행**

### 인증 실패 시

다음 경고창이 뜨고 **프로그램이 즉시 종료**됩니다.

**실패 원인**:
- `license.lic` 파일 없음
- 다른 PC의 라이선스 복사
- 하드웨어 변경 (CPU, 메인보드, 디스크 등)
- 파일 위변조

---

## 2.4 문제 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| 라이선스 파일 없음 | `license.lic` 미배치 | 설치 폴더에 복사 |
| 하드웨어 불일치 | PC 교체/부품 변경 | 관리자에게 재발급 요청 |
| 실행 파일만 복사 | Setup 미실행 | Setup.exe 로 정식 설치 |
| 파일명 오류 | `license.lic.txt` 등 | 확장자 확인 후 `license.lic` 로 수정 |

---

## 2.5 제거 및 업데이트

### 제거
**제어판 → 프로그램 및 기능 → Coupling Matrix Wizard 2026 → 제거**

### 업데이트
- **자동 업데이트** 지원 (ClickOnce)
- 또는 관리자로부터 새 `Setup.exe` 수령 후 재설치
- 재설치 시 `license.lic` 은 그대로 유지 (동일 PC)
