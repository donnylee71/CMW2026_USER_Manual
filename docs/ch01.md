# Chapter 1. 개요

## 1.1 CMW2026이란?

**Coupling Matrix Wizard 2026 (CMW2026)** 은 마이크로파 **대역통과 필터(Band-Pass Filter)** 를 설계하고 분석하기 위한 **전문 소프트웨어**입니다. RF 및 마이크로파 공학의 **커플링 매트릭스(Coupling Matrix) 이론**을 기반으로, 필터의 S-파라미터를 **실시간으로 계산·시각화**하고, 최적화 알고리즘으로 매트릭스를 자동 튜닝합니다.

기존에는 MATLAB, ADS, CST 등의 고가 상용 툴이나 엑셀 기반 수작업 계산에 의존하던 필터 설계 과정을, **하나의 직관적인 Windows 프로그램**으로 통합하여 **설계 시간을 획기적으로 단축**합니다.

## 1.2 왜 CMW2026을 만들었나? (제작 목적)

### 1.2.1 기존 설계 방식의 문제점

마이크로파 필터 설계는 전통적으로 다음과 같은 **번거로운 과정**을 거칩니다.

| 기존 방식 | 문제점 |
|----------|--------|
| **엑셀 수작업 계산** | Chebyshev g-파라미터, S-파라미터를 일일이 수식으로 계산 → 오류 위험, 시간 소모 |
| **MATLAB 스크립트** | 별도 스크립트 작성 필요, 비전공자에게 진입 장벽 |
| **상용 툴 (ADS, CST)** | 고가 라이선스, 복잡한 UI, 단순 필터 설계에는 과도한 기능 |
| **반복 시행착오** | 매트릭스 값을 수동으로 바꿔가며 최적점을 찾는 데 많은 시간 소요 |
| **TZ 설계 어려움** | Transmission Zero 배치를 물리적으로 해석하기 어려움 |

### 1.2.2 CMW2026의 목표

CMW2026은 위 문제를 해결하기 위해 다음을 목표로 개발되었습니다.

1. **직관적인 UI**: 복잡한 스크립트 없이 **입력 → 실행 → 결과**의 3단계로 설계
2. **실시간 시각화**: 매트릭스 값을 바꾸면 **즉시 S-파라미터 파형 갱신**
3. **자동 최적화**: Simplex 알고리즘으로 **매트릭스를 자동 튜닝**하여 Goals 달성
4. **TZ 설계 지원**: Cross-Coupling을 통한 **전송 영점**을 쉽게 배치하고 시각화
5. **온도 시뮬레이션**: Δf/ΔQu를 입력하여 **극한 온도에서의 성능**을 미리 예측
6. **표준 포맷 지원**: Touchstone(.s2p), CSV 등 **상용 툴과의 연동**

### 1.2.3 어떤 사용자를 위해?

| 사용자 | CMW2026 활용 |
|--------|-------------|
| **필터 설계 초보자** | Chebyshev 합성 원리를 시각적으로 이해하고, 자동 튜닝으로 빠르게 결과 도출 |
| **RF 엔지니어** | 실제 캐비티/모노블럭 필터의 매트릭스를 설계하고 튜닝 |
| **연구자/학생** | 커플링 매트릭스 이론, TZ 생성 원리를 실험적으로 검증 |
| **생산/품질 담당자** | 온도 마진, 수율 분석으로 양산 안정성 확보 |

## 1.3 주요 기능 (Key Features)

CMW2026은 **6가지 핵심 기능**을 제공합니다.

### 1.3.1 Filter(CBW) 모드 — 매트릭스 기반 시뮬레이션

필터의 **커플링 매트릭스**(Fi, CBW, Qe)를 직접 편집하며, **행렬 방정식**으로 S-파라미터를 실시간 계산합니다.

- 매트릭스 셀 **직접 입력 / 마우스 휠 조정**
- **Lock/Unlock**으로 특정 셀 보호
- **Undo/Redo** (최대 50단계)
- Cross-Coupling 입력 시 **TZ(전송 영점) 자동 생성**
- **Overlay Synth**로 Filter vs Synthesize 파형 비교

### 1.3.2 Synthesize 모드 — Chebyshev 이상 파형

**Chebyshev 합성 이론**으로 목표 스펙(Fc, BW, RL, TZ)에 완벽히 일치하는 **이론적 이상 파형**을 생성합니다.

- N, RL, Qu, Fc, BW 입력 → **g-파라미터 자동 계산**
- **Synthesize TZ** 테이블에서 TZ를 직접 입력/편집/드래그
- **RL/TZ Auto Tuning** (Coordinate Descent)으로 Goals 달성
- 매트릭스와 **완전히 독립** (Synthesize는 매트릭스를 읽지도, 쓰지도 않음)

### 1.3.3 Auto Tuning — 자동 매트릭스 최적화

**Nelder-Mead Simplex** 알고리즘으로 매트릭스를 자동 튜닝하여 **Optimization Goals**(최적화 마스크)를 달성합니다.

- **Resonator / Coupling / Qe** 등 선택적 튜닝
- **Auto Restart**: 수렴 실패 시 5초 간격으로 최대 10회 재시작
- **Resume**: Stop 후 현재 상태에서 재시작
- **실시간 ProgressBar + 파형 갱신**
- **Best Cost 복원**: 최적화 종료 시 최선 상태로 복원

### 1.3.4 Temp Simulation — 온도 시뮬레이션

온도 변화에 따른 **중심 주파수 이동(Δf)** 과 **Q 저하(ΔQu)** 를 시뮬레이션합니다.

- **Δf, ΔQu** 입력 → **Temp 파형 자동 생성** (점선)
- **Orig / Temp** 전환으로 원본과 비교
- **GD Temp** 시리즈도 자동 생성
- **Average Loss** 테이블이 Temp 기준으로 자동 재계산
- Filter 모드 / Synthesize 모드 **독립 상태 관리**

### 1.3.5 마커 및 그래프 분석

그래프의 특정 지점에서 정확한 값을 읽고 비교하는 **마커 시스템**을 제공합니다.

- **그래프 클릭** 또는 **Add MK**로 마커 추가
- **다중/범위 입력** 지원 (예: `1950-2050`)
- **자동 마커**(흰색) / **수동 마커**(연노랑) / **Compare 마커**(Cyan)
- **Marker Table**에서 주파수/값 편집
- **SmartLabelStyle**로 라벨 겹침 자동 회피

### 1.3.6 데이터 입출력

설계 결과를 **외부 파일**로 저장하고, 다른 프로젝트로 이식합니다.
