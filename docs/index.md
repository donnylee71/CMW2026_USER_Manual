---

## 🚀 빠른 시작

1. **Filter Input Parameter**에서 N, RL, Qu, F_Start, F_Stop 입력
2. 각 필드에서 `Enter` 키로 확정
3. **Filter** 버튼 클릭
4. 그래프에서 S-Parameter 파형 확인

!!! tip "TIP"
    대부분의 입력은 **Enter** 키로 확정해야 반영됩니다.

!!! warning "WARNING"
    Auto Tuning 중에는 매트릭스 편집이 제한됩니다.
