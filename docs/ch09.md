(function() {
  function initGlossarySearch() {
    var searchInput = document.getElementById('glossarySearch');
    var filterBtns = document.querySelectorAll('.glossary-filter-btn');
    var cards = document.querySelectorAll('.glossary-card');
    var countEl = document.getElementById('glossaryCount');
    var emptyMsg = document.getElementById('glossaryEmpty');
    if (!searchInput || !cards.length) return;

    var currentCat = 'all';

    function updateCount(visible) {
      if (countEl) {
        countEl.innerHTML = '검색 결과 <strong>' + visible + '</strong>개 용어 / 전체 ' + cards.length + '개';
      }
      if (emptyMsg) {
        emptyMsg.style.display = (visible === 0) ? 'block' : 'none';
      }
    }

    function applyFilter() {
      var q = searchInput.value.trim().toLowerCase();
      var visible = 0;
      cards.forEach(function(card) {
        var cat = card.getAttribute('data-cat') || '';
        var catMatch = (currentCat === 'all') || (cat === currentCat);
        var text = card.textContent.toLowerCase();
        var qMatch = (q === '') || text.indexOf(q) !== -1;
        if (catMatch && qMatch) {
          card.style.display = '';
          visible++;
        } else {
          card.style.display = 'none';
        }
      });
      updateCount(visible);
    }

    searchInput.addEventListener('input', applyFilter);
    filterBtns.forEach(function(btn) {
      btn.addEventListener('click', function() {
        filterBtns.forEach(function(b) { b.classList.remove('active'); });
        btn.classList.add('active');
        currentCat = btn.getAttribute('data-cat');
        applyFilter();
      });
    });

    // 초기 카운트
    updateCount(cards.length);
  }

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', initGlossarySearch);
  } else {
    initGlossarySearch();
  }
})();
</script>

## 1. 기본 개념 (Basic Concepts)

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Filter <span class="term-abbr">필터</span></div>
  <div class="term-kr">특정 주파수 대역의 신호를 통과시키거나 차단하는 수동 소자 회로</div>
  <div class="term-def">CMW2026은 Chebyshev 대역통과 필터(Band-Pass Filter)를 다룹니다. 필터는 통과대역(Pass Band)과 저지대역(Stop Band)을 구분하여 원하는 신호만 선택적으로 통과시킵니다.</div>
  <div class="term-related">관련: <a href="../ch01/">Ch 1. 개요</a> <a href="../ch04/">Ch 4. Synthesize</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Band-Pass Filter <span class="term-abbr">BPF</span></div>
  <div class="term-kr">대역통과 필터</div>
  <div class="term-def">특정 주파수 대역만 통과시키고 나머지는 차단하는 필터. 저역통과(LPF)와 고역통과(HPF)의 조합으로 구현됩니다. CMW2026의 주 대상입니다.</div>
  <div class="term-related">관련: <a href="../ch04/">Ch 4</a> <a href="../ch05/">Ch 5</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Resonator <span class="term-abbr">공진기</span></div>
  <div class="term-kr">공진기, 공진 회로</div>
  <div class="term-def">특정 주파수에서 공진하는 소자. 필터는 N개의 공진기를 커플링으로 연결하여 구성됩니다. 캐비티, 유전체, 도파관, 모노블럭 등 다양한 형태가 있습니다.</div>
  <div class="term-related">관련: <a href="../ch05/#521-매트릭스-구조">Ch 5.2.1 매트릭스 구조</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Pole / Order (N) <span class="term-abbr">차수</span></div>
  <div class="term-kr">필터 차수, 극점 수</div>
  <div class="term-def">필터의 공진기 수. N이 클수록 선택도가 좋아지지만 삽입 손실과 크기가 증가합니다. CMW2026은 N=2~20까지 지원합니다.</div>
  <div class="term-related">관련: <a href="../ch03/#331-filter-input-parameter-필터-입력-파라미터">Ch 3.3.1</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Pass Band</div>
  <div class="term-kr">통과대역</div>
  <div class="term-def">필터가 신호를 통과시키는 주파수 대역. F_Start ~ F_Stop 사이. S21이 최대(0dB에 가까움)입니다.</div>
  <div class="term-related">관련: <a href="../ch05/#53-optimization-goals-최적화-목표-입력">Ch 5.3</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Stop Band</div>
  <div class="term-kr">저지대역</div>
  <div class="term-def">필터가 신호를 차단하는 주파수 대역. S21이 최소(예: -40dB 이하)입니다.</div>
  <div class="term-related">관련: <a href="../ch05/#53-optimization-goals-최적화-목표-입력">Ch 5.3</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Insertion Loss <span class="term-abbr">IL</span></div>
  <div class="term-kr">삽입 손실</div>
  <div class="term-def">필터를 삽입했을 때 통과대역에서 발생하는 신호 감쇠(dB). Qu(무부하 Q)와 FBW에 반비례합니다: `IL ≈ 1/(Qu · FBW)`.</div>
  <div class="term-related">관련: <a href="../ch05/#57-average-loss-평균-손실">Ch 5.7 Average Loss</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Return Loss <span class="term-abbr">RL</span></div>
  <div class="term-kr">반사 손실</div>
  <div class="term-def">입력에서 반사되는 신호의 비율(dB). `RL = -20·log10(|S11|)`. 클수록 매칭이 좋습니다. 보통 15~25dB.</div>
  <div class="term-related">관련: <a href="../ch03/#331-filter-input-parameter-필터-입력-파라미터">Ch 3.3.1</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Ripple</div>
  <div class="term-kr">리플</div>
  <div class="term-def">통과대역 내 S11의 최대-최소 진폭 차이(dB). Chebyshev 필터의 특징. RL 값으로부터 유도됩니다.</div>
  <div class="term-related">관련: <a href="../ch04/">Ch 4</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">FBW (Fractional Bandwidth)</div>
  <div class="term-kr">분수 대역폭, 상대 대역폭</div>
  <div class="term-def">`FBW = BW / Fc`. 대역폭을 중심 주파수로 나눈 비율. 필터 설계의 핵심 정규화 파라미터입니다.</div>
  <div class="term-related">관련: <a href="../ch05/">Ch 5</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Chebyshev Filter</div>
  <div class="term-kr">체비쇼프 필터</div>
  <div class="term-def">통과대역에 리플을 허용하는 대신 가파른 스커트 특성을 얻는 필터. 가장 널리 쓰이는 필터 타입. CMW2026의 기본 합성 방식입니다.</div>
  <div class="term-related">관련: <a href="../ch04/">Ch 4</a> <a href="../ch05/">Ch 5</a></div>
</div>

<div class="glossary-card" data-cat="basic">
  <div class="term-main">Butterworth Filter</div>
  <div class="term-kr">버터워스 필터</div>
  <div class="term-def">통과대역에 리플이 없는 최대 평탄(Maximally Flat) 필터. Chebyshev보다 스커트가 완만합니다.</div>
  <div class="term-related">관련: <a href="../ch04/">Ch 4</a></div>
</div>

## 2. 커플링 매트릭스 (Coupling Matrix)

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">Coupling Matrix</div>
  <div class="term-kr">커플링 매트릭스</div>
  <div class="term-def">필터의 공진기 간 커플링을 행렬로 표현한 것. (N+2)×(N+2) 대칭 행렬. 대각선은 공진 주파수(Fi), 비대각은 커플링(CBW), Source/Load는 외부 Q(Qe)입니다.</div>
  <div class="term-related">관련: <a href="../ch05/#52-filter-coupling-matrix-이해-및-편집">Ch 5.2</a></div>
</div>

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">Coupling (M) <span class="term-abbr">M_ij</span></div>
  <div class="term-kr">커플링, 결합 계수</div>
  <div class="term-def">공진기 i와 j 사이의 전자기적 결합 정도. CMW2026에서는 CBW(Coupling Bandwidth) 단위(MHz)로 표시됩니다.</div>
  <div class="term-related">관련: <a href="../ch05/#522-셀의-종류와-색상-의미">Ch 5.2.2</a></div>
</div>

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">Main Coupling</div>
  <div class="term-kr">주 커플링</div>
  <div class="term-def">인접한 공진기(i, i+1) 사이의 커플링. 매트릭스에서 대각선 바로 옆 셀(연녹색). 필터의 기본 대역폭을 결정합니다.</div>
  <div class="term-related">관련: <a href="../ch05/#522-셀의-종류와-색상-의미">Ch 5.2.2</a></div>
</div>

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">Cross Coupling</div>
  <div class="term-kr">교차 커플링</div>
  <div class="term-def">비인접 공진기(i, j, |i-j|≥2) 사이의 커플링. 매트릭스에서 대각선에서 먼 셀(흰색). TZ(전송 영점)를 생성합니다.</div>
  <div class="term-related">관련: <a href="../ch05/#544-방법-③-filter-tz-테이블-참조">Ch 5.4</a></div>
</div>

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">CBW (Coupling Bandwidth)</div>
  <div class="term-kr">커플링 대역폭</div>
  <div class="term-def">커플링 계수를 대역폭 단위(MHz)로 표현한 것. `CBW = M · BW`. CMW2026 매트릭스에 표시되는 값입니다.</div>
  <div class="term-related">관련: <a href="../ch05/#522-셀의-종류와-색상-의미">Ch 5.2.2</a></div>
</div>

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">Fi (Resonant Frequency)</div>
  <div class="term-kr">공진 주파수</div>
  <div class="term-def">각 공진기 i의 공진 주파수(MHz). 매트릭스 대각선 셀(노란색). 이상적으로는 모두 Fc와 같지만, 실제로는 미세 조정이 필요합니다.</div>
  <div class="term-related">관련: <a href="../ch05/#522-셀의-종류와-색상-의미">Ch 5.2.2</a></div>
</div>

<div class="glossary-card" data-cat="matrix">
  <div class="term-main">Qe (External Q)</div>

  <div class="term-def">비율의 로그 단위. S-파라미터, RL, 삽입 손실 등에 사용됩니다.</div>
  <div class="term-related">관련: <a href="../ch05/">Ch 5</a></div>
</div>

<div class="glossary-card" data-cat="unit">
  <div class="term-main">ns (Nanosecond)</div>
  <div class="term-kr">나노초</div>
  <div class="term-def">시간 단위. 1 ns = 10⁻⁹ s. Group Delay의 기본 단위입니다.</div>
  <div class="term-related">관련: <a href="../ch05/#561-파형-표시-제어">Ch 5.6.1</a></div>
</div>

<div class="glossary-card" data-cat="unit">

  <div class="term-kr">옴</div>
  <div class="term-def">임피던스 단위. 시스템 기준 임피던스는 보통 50Ω.</div>
  <div class="term-related">관련: <a href="../ch08/">Ch 8</a></div>

<div class="glossary-card" data-cat="unit">

<div class="glossary-card" data-cat="unit">

  <div class="term-kr">분수 대역폭</div>
