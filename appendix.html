    A. 시작 및 설치¶

    Q1. 프로그램이 실행되지 않습니다.¶

    A. 다음을 순서대로 확인하세요.

    1. .NET Framework 4.7.2 이상이 설치되어 있는지 확인합니다. (Windows 10 이후 기본 포함)
    2. license.lic 파일이 실행 폴더에 있는지 확인합니다. 없으면 "개발자 모드" 경고가 뜨지만 실행은 됩니다. 실행 자체가 안 되면 Windows Defender / 백신이 차단했을 수 있으니 예외 처리하세요.
    3. MathNet.Numerics.dll 이 실행 파일과 같은 폴더에 있는지 확인합니다.
    4. 이벤트 뷰어(Windows 로그 → 응용 프로그램)에서 오류 내용을 확인합니다.
    5. 위 방법으로도 해결되지 않으면 기술 지원(donnylee@partron.co.kr) 으로 로그와 함께 문의하세요.

    Q2. "라이선스 파일(license.lic)을 찾을 수 없습니다" 경고가 뜹니다.¶

    A. 이 경고는 개발자 모드로 실행 중임을 알리는 것입니다.

    • 정식 사용: license.lic 파일을 실행 폴더에 배치합니다.
    • 개발/테스트: 경고창에서 "확인"을 누르면 모든 기능을 사용 가능합니다. 다만 상용 배포 시에는 반드시 라이선스 파일을 동봉하세요.

    Q3. 다른 PC에서 실행했더니 라이선스 오류가 납니다.¶

    A. CMW2026의 라이선스는 PC의 하드웨어 핑거프린트(고유 ID) 기반입니다. PC가 바뀌면 라이선스가 무효화됩니다.

    • 새 PC의 핑거프린트로 라이선스 재발급을 요청하세요. (기술 지원 이메일)
    • 개발자 모드로 임시 사용은 가능합니다. (경고창 무시)

    Q4. 프로그램 초기 화면이 나오지 않고 흰 화면만 보입니다.¶

    A. 다음을 확인하세요.

    1. 로그(ListBox) 에 오류가 있는지 확인합니다. ERROR 레벨 항목을 찾으세요.
    2. Form1_Load 에서 예외가 발생했을 가능성이 있습니다. 로그에 "Form1_Load: dgvTargetMatrix가 Nothing입니다!" 같은 메시지가 있으면 컨트롤 초기화 실패입니다.
    3. 프로그램을 완전히 종료 후 재실행합니다.
    4. 그래도 안 되면 Clear All 또는 설정 파일 삭제 후 재실행합니다.

    Q5. 처음 실행 시 "최적화 Goals 1~4행 자동 입력" 이 되지 않습니다.¶

    A. 다음을 확인하세요.

    • txtMatFc / txtMatBW / txtGenRL / txtFStart / txtFStop 이 비어있지 않은지 확인합니다.
    • Goals 테이블에 이미 수동 편집(isGoalsManuallyEdited = True) 상태라면 자동 갱신이 스킵됩니다. Clear All 후 다시 실행해 보세요.

    Q6. 개발자 모드와 정식 모드의 기능 차이가 있나요?¶

    A. 없습니다. 라이선스가 없어도 모든 기능을 사용할 수 있습니다. 다만 프로그램 시작 시 경고창이 뜨고, 로그에 "개발자 모드" 경고가 남습니다. 상용 배포 시에는 반드시 라이선스 파일을 동봉하세요.

    B. 화면 및 UI¶

    Q7. 화면이 너무 작아서 그래프가 잘 보이지 않습니다.¶

    A. 세 가지 방법이 있습니다.

    1. Window Setting 그룹에서 Left Rate(%) 를 줄이고 Table Rate(%) 를 늘립니다. (예: Left 40%, Table 85%)
    2. 그래프 영역을 마우스 더블클릭하면 팝아웃(Pop-out) 창으로 분리되어 크게 볼 수 있습니다.
    3. 창을 최대화하거나, 모니터 해상도를 높입니다. (권장 1920×1080)

    Q8. 텍스트박스에 값을 입력했는데 반영되지 않습니다.¶

    A. CMW2026의 대부분의 텍스트박스는 Enter 키를 눌러야 확정됩니다. 마우스로 다른 곳을 클릭하거나 탭 이동만으로는 반영되지 않습니다.

    • 해결: 값을 입력한 후 반드시 Enter 키를 누르세요.
    • 예외: Marker Table의 주파수 셀은 직접 입력 후 Enter로 확정합니다.

    Q9. 체크박스를 켰는데 파형이 표시되지 않습니다.¶

    A. 다음을 확인하세요.

    1. Filter 또는 Synthesizer 버튼이 활성화(색상 변경)되어 있는지 확인합니다.
    2. S11/S21/S22 체크박스가 켜져 있는지 확인합니다.
    3. ESC 또는 Space 키로 축 리셋을 시도합니다. (줌 상태에서 파형이 화면 밖에 있을 수 있음)
    4. 로그에 PlotSParameters 관련 오류가 있는지 확인합니다.

    Q10. 화면의 글자가 너무 작아서 보기 힘듭니다.¶

    A. Windows의 디스플레이 설정 → 배율(125%, 150%) 을 조정하세요. 다만 CMW2026은 AutoScaleMode.None으로 설정되어 있어, 배율 변경 시 레이아웃이 어긋날 수 있습니다. 이 경우 창 크기를 수동으로 조정하세요.

    Q11. 화면이 자꾸 깜빡입니다.¶

    A. Auto Tuning 중이거나 대량의 마커가 있을 때 발생할 수 있습니다.

    • Auto Tuning 중: 정상 동작입니다. (실시간 파형 갱신)
    • 다량 마커: Clear All Manual Markers로 마커를 정리하세요.
    • Temp Simulation: Δf/ΔQu를 0으로 설정하면 Temp 시리즈가 Clear됩니다.

    Q12. 원래 화면 배치로 되돌리고 싶습니다.¶

    A. Window Setting 그룹에서 Left Rate(%) 를 60, Table Rate(%) 를 75로 설정합니다. 또는 Clear All 후 재실행하면 초기 레이아웃으로 복원됩니다.

    Q13. 로그(ListBox)의 내용이 너무 많아서 느려집니다.¶

    A. 로그는 최대한 간결하게 유지되지만, 장시간 사용 시 누적됩니다.

    • 우클릭 → 로그 지우기로 초기화합니다.
    • Ctrl+A로 전체 선택 후 Ctrl+Shift+Delete로 삭제할 수 있습니다 (지원 시).
    • 필요 없는 로그는 우클릭 → 선택 삭제로 제거합니다.

    Q14. 로그를 복사해서 기술 지원에 보내고 싶습니다.¶

    A. 다음 방법으로 복사합니다.

    • 선택 복사: Ctrl+C (선택된 항목만)
    • 전체 복사: Ctrl+Shift+C (모든 로그)
    • 또는 우클릭 → 전체 로그 복사 클릭

    복사한 내용을 이메일 본문에 붙여넣어 기술 지원에 보내면 됩니다.

    C. Filter(CBW) 모드¶

    Q15. Filter 모드에서 파형이 전혀 표시되지 않습니다.¶

    A. 다음을 확인하세요.

    1. Filter 버튼이 파란색(활성) 상태인지 확인합니다.
    2. S11/S21/S22 체크박스가 켜져 있는지 확인합니다.
    3. 매트릭스 초기값이 모두 0인지 확인합니다. (0이면 파형이 나오지 않습니다)
    4. Clear All 후 재실행하거나, Synthesize 모드에서 합성 후 Filter 모드로 전환합니다.
    5. 로그에 "PlotSParameters" 오류가 있는지 확인합니다.

    Q16. 매트릭스 값을 편집했는데 파형이 변하지 않습니다.¶

    A. 다음을 확인하세요.

    1. Filter 모드가 활성화되어 있는지 확인합니다. (Synthesize 모드에서는 매트릭스가 무시됩니다)
    2. Enter 키를 눌러 편집을 확정했는지 확인합니다.
    3. 해당 셀이 Lock 상태인지 확인합니다. (Lock된 셀은 편집이 차단됩니다)
    4. 로그에 "HandleMatrixEdit" 관련 오류가 있는지 확인합니다.

    Q17. 매트릭스 셀을 마우스 휠로 조정했는데 너무 크게 변합니다.¶

    A. Auto Tuning 그룹의 Freq. Step (Fi 셀) 또는 Coupling Step (CBW 셀) 값을 조정하세요.

    • 현재 값: 기본 5 MHz (매우 큼)
    • 권장 값: 세밀 조정 시 1 또는 0.5
    • 이 값은 수동 휠 조정 전용이며, Auto Tuning에는 영향을 주지 않습니다.

    Q18. "Ignore M_ij"가 무엇인가요?¶

    A. Ignore M_ij <= 입력란(기본 0.001)은 Auto Tuning에서 무시할 커플링의 임계값입니다.

    • 값이 0.001 미만인 셀은 회색 글자로 표시됩니다.
    • Auto Tuning 시 이 셀들은 튜닝 대상에서 제외됩니다.
    • 불필요한 미세 커플링을 무시하여 최적화 효율을 높이는 데 유용합니다.

    Q19. Lock 기능은 어떻게 사용하나요?¶

    A. 특정 셀을 Auto Tuning 중에도 변경되지 않도록 보호하는 기능입니다.

    1. 개별 Lock: 셀 우클릭 → Toggle Lock / Unlock Cell → 엷은 주황색 배경으로 변경
    2. 전체 Lock: 상단 Unlocked / Locked 버튼 클릭 → 전체 토글

    Auto Tuning 시 Lock된 셀은 자동으로 튜닝 대상에서 제외됩니다.

    Q20. Undo/Redo가 동작하지 않습니다.¶

    A. 다음을 확인하세요.

    1. Filter 모드가 활성화되어 있는지 확인합니다. (Synthesize 모드에서는 매트릭스 편집이 없어 Undo 스택이 비어있습니다)
    2. Ctrl+Z (Undo) / Ctrl+Y (Redo) 단축키 또는 ↶ Undo / ↷ Redo 버튼을 사용합니다.
    3. Undo 스택은 최대 50단계까지만 기억합니다.
    4. Clear All 또는 파일 로드 시 스택이 초기화됩니다.

    Q21. Optimization Goals에 목표를 입력했는데 파형이 그에 맞게 변하지 않습니다.¶

    A. Goals는 Auto Tuning을 실행해야 반영됩니다. Goals는 "달성해야 할 목표"일 뿐, 자동으로 파형이 변경되지는 않습니다.

    • 해결: Goals 입력 → Auto Tuning 그룹에서 Start 클릭 → 최적화 실행

    Q22. TZ를 그래프에서 직접 추가하고 싶습니다.¶

    A. Filter 모드에서는 TZ를 그래프에서 직접 추가할 수 없습니다. TZ는 매트릭스의 Cross-Coupling 값을 통해서만 생성됩니다.

    • Filter 모드: 매트릭스의 Cross-Coupling 셀(예: (2,5), (1,6))에 값을 입력 → TZ 자동 생성 → Filter TZ 테이블에 표시
    • Synthesize 모드: 그래프 우클릭 → Add TZ 또는 TZ 테이블 직접 입력 가능

    Q23. TZ를 그래프에서 드래그로 이동하고 싶습니다.¶

    A. Filter 모드에서는 TZ 드래그가 지원되지 않습니다. TZ 드래그는 Synthesize 모드 전용 기능입니다.

    • Filter 모드: 매트릭스 Cross-Coupling 셀을 마우스 휠로 조정 → TZ 위치 이동
    • Synthesize 모드: 그래프 TZ 세로 가이드선 드래그 → TZ 이동

    Q24. Filter TZ 테이블의 값을 편집하고 싶습니다.¶

    A. Filter TZ 테이블은 표시 전용(읽기 전용) 입니다. 값을 편집하여 매트릭스나 파형을 변경할 수 없습니다.

    • TZ를 조정하려면: 매트릭스의 해당 Cross-Coupling 셀 값을 변경하세요.
    • TZ 정보를 참조하려면: Filter TZ 테이블의 주파수/깊이를 읽기만 하세요.

    D. Synthesize 모드¶

    Q25. Synthesize 모드에서 파형이 표시되지 않습니다.¶

    A. 다음을 확인하세요.

    1. Synthesizer 버튼이 초록색(활성) 상태인지 확인합니다.
    2. S11/S21/S22 체크박스가 켜져 있는지 확인합니다.
    3. N, BW, RL, Qu 값이 유효한지 확인합니다.
    4. Fc (F_Start_Design, F_Stop_Design)가 유효한지 확인합니다.
    5. 로그에 "FilterSynthesizer.ExactSParameters" 오류가 있는지 확인합니다.

    Q26. Synthesize 모드의 Auto Tuning이 어떤 일을 하나요?¶

    A. Synthesize 모드의 Auto Tuning은 RL(반사 손실) 과 TZ(전송 영점) 를 최적화합니다.

    • 최적화 대상: RL, TZ 주파수
    • 고정 대상: N, Fc, BW, Qu (특히 Qu는 재료 물성치로 절대 변하지 않음)
    • 방식: Coordinate Descent (RL → TZ → RL → ...)
    • 검증: S11/S22 페널티가 10% 이상 악화되면 자동으로 원본 복원

    Filter 모드의 Auto Tuning과는 완전히 다른 엔진입니다.

    Q27. Synthesize 모드에서 매트릭스를 편집할 수 없습니다.¶

    A. 정상 동작입니다. Synthesize 모드는 Chebyshev 합성 파라미터(N, Fc, BW, RL, Qu, TZ)만 사용하며, Coupling Matrix를 읽지도, 쓰지도 않습니다. 매트릭스 패널이 회색으로 비활성화되는 것이 정상입니다.

    Q28. Synthesize TZ 테이블에 값을 입력했는데 파형이 변하지 않습니다.¶

    A. 다음을 확인하세요.

    1. Synthesize 모드가 활성화되어 있는지 확인합니다. (Filter 모드에서는 Synthesize TZ가 숨겨집니다)
    2. TZ 테이블의 0행 Freq에 값을 입력했는지 확인합니다. (1행 Value는 읽기 전용)
    3. Enter 키로 확정했는지 확인합니다.
    4. TZ 값을 0.5MHz 단위로 반올림했는지 확인합니다. (입력 시 자동 반올림)

    Q29. Synthesize TZ를 삭제하고 싶습니다.¶

    A. 세 가지 방법이 있습니다.

    1. 테이블에서: TZ 셀을 비우고 Enter
    2. 우클릭 메뉴: TZ 테이블 우클릭 → 선택한 TZ 삭제 또는 모든 TZ 삭제 (Clear All)
    3. 그래프 우클릭: Delete TZ (마커 위에 있으면 해당 TZ, 아니면 커서에서 가장 가까운 TZ)

    Q30. Synthesize 모드에서 RL/TZ 최적화 결과가 만족스럽지 않습니다.¶

    A. 다음을 시도하세요.

    1. TZ를 수동으로 조정: TZ 테이블에서 직접 값을 조정하거나 그래프에서 드래그
    2. RL 값 조정: txtGenRL 값을 직접 변경
    3. 다시 Start 클릭: 좀 더 나은 국소 최적점을 찾을 수 있음
    4. N 재검토: N이 부족하면 Goals 자체를 만족할 수 없으므로 N을 늘림
    5. Threshold 완화: 0.001 → 0.005로 완화하면 조기 수렴 유도

    E. Auto Tuning¶

    Q31. Auto Tuning이 시작되지 않습니다.¶

    A. 다음을 확인하세요.

    1. Optimization Goals가 비어있지 않은지 확인합니다. (Target, F_Start, F_Stop이 모두 유효해야 함)
    2. N이 2 이상인지 확인합니다.
    3. isOptimizing 플래그가 이미 True인지 확인합니다. (이미 실행 중이면 중복 실행 불가)
    4. 로그에 "유효한 Optimization Goals가 없습니다" 메시지가 있는지 확인합니다.

    Q32. Auto Tuning이 실행되지만 수렴하지 않습니다.¶

    A. 다음을 시도하세요.

    1. Threshold 완화: 0.001 → 0.01로 완화하면 조기 수렴
    2. Precision 증가: 50 → 100으로 정밀도 향상
    3. Max Iter 증가: 50 → 100으로 반복 횟수 증가
    4. Tune Limit 조정: 30% → 50%로 범위 확대 (단, 물리적으로 비현실적일 수 있음)
    5. Lock/Unlock 재조정: 의심되는 셀만 Lock 해제
    6. N 재검토: Goals를 만족할 수 없는 N이면 Auto Tuning이 아무리 돌아도 수렴하지 않습니다.

    Q33. Auto Tuning 중 "Stop" 버튼을 눌렀는데 반응이 없습니다.¶

    A. 다음을 확인하세요.

    1. Stop 버튼이 빨간색(활성) 상태인지 확인합니다.
    2. _optimizationCts.Cancel() 이 호출되었는지 로그에서 "Stop 클릭" 메시지를 확인합니다.
    3. 반응이 없으면 Auto Tuning이 이미 종료된 상태일 수 있습니다. ProgressBar가 100%인지 확인하세요.
    4. 그래도 안 되면 프로그램을 재시작합니다.

    Q34. Auto Tuning 후 "Resume" 버튼이 비활성화되어 있습니다.¶

    A. Resume은 Stop 후에만 활성화됩니다.

    • Auto Tuning 실행 중: Start 비활성, Stop 활성
    • Stop 클릭 후: Resume 활성
    • Auto Tuning 완료 후: Resume 비활성 (Start 다시 클릭)

    또한 Synthesize 모드에서는 Resume이 비활성화됩니다. (Start로 재시작)

    Q35. Auto Restart가 계속 반복됩니다.¶

    A. Auto Restart는 최대 10회까지만 재시작합니다. 10회 후에도 Threshold에 도달하지 못하면 자동 종료됩니다.

    • 로그에 "최대 재시작 횟수 도달" 메시지가 있는지 확인합니다.
    • Interval (s) 값을 늘리면 재시작 간격이 길어집니다. (기본 5초)
    • Auto Restart 체크 해제로 수동 제어할 수 있습니다.

    Q36. Auto Tuning 도중 파형이 이상하게 요동칩니다.¶

    A. 정상 동작입니다. Auto Tuning은 매트릭스를 반복 조정하며 파형을 실시간 갱신합니다. 최종 결과는 Best Cost 상태로 복원됩니다. 최종 결과만 확인하려면 Auto Tuning 완료 후 파형을 보세요.

    Q37. Auto Tuning 후 매트릭스 값이 초기값과 완전히 다릅니다.¶

    A. Auto Tuning은 Best Cost를 달성한 매트릭스로 복원됩니다. 초기값과 다를 수 있습니다.

    • Best Cost 복원: 최적화 종료 시 가장 좋았던 상태로 복원
    • 초기값 복원을 원하면: Undo (Ctrl+Z)를 사용하거나, 파일 저장 전 상태로 되돌립니다.
    • Auto Tuning 전에 저장을 권장합니다. (Ctrl+S)

    Q38. "Simplex 최적화 완료" 로그가 뜨는데 Cost가 여전히 큽니다.¶

    A. Simplex가 국소 최적점(Local Minima) 에 갇혔을 수 있습니다. 다음을 시도하세요.

    1. Resume 버튼으로 재시작
    2. Auto Restart 체크 → 5초마다 재시작
    3. Threshold 완화 (0.001 → 0.01)
    4. Precision 증가 (50 → 100)
    5. Tune Limit 확대 (30% → 50%)
    6. Lock 해제: 모든 셀을 Unlock하고 다시 시도

    Q39. Auto Tuning 중 다른 작업을 할 수 없나요?¶

    A. Auto Tuning 중에는 매트릭스 편집이 제한됩니다. 파형과 ProgressBar만 갱신됩니다. 다른 작업이 필요하면 Stop 후 진행하세요.

    Q40. Auto Tuning 로그를 파일로 저장하고 싶습니다.¶

    A. 로그(ListBox)를 Ctrl+Shift+C 로 전체 복사한 후, 메모장에 붙여넣어 저장합니다. 또는 우클릭 → 전체 로그 복사를 사용합니다. 로그 파일은 기술 지원 문의 시 함께 보내면 유용합니다.

    F. 마커 및 그래프¶

    Q41. 그래프를 클릭해도 마커가 추가되지 않습니다.¶

    A. 다음을 확인하세요.

    1. 좌클릭인지 확인합니다. (우클릭은 컨텍스트 메뉴)
    2. TZ 드래그 중이 아닌지 확인합니다.
    3. 줌 드래그 중이 아닌지 확인합니다.
    4. 클릭 지점에서 20px 이내에 데이터 포인트가 있는지 확인합니다.
    5. 해당 시리즈(S21 등)가 체크되어 있는지 확인합니다.

    Q42. 특정 시리즈(S11, S22)에 마커를 추가하고 싶습니다.¶

    A. 그래프 클릭은 가장 가까운 시리즈에 자동으로 마커를 추가합니다. 특정 시리즈를 지정하려면 Add MK 방법을 사용하세요.

    1. 그래프 우클릭 → Add MK
    2. S-Param 콤보박스에서 S11, S21, S22, GD11, GD21, GD22, Compare S11/S21/S22 중 선택
    3. 주파수 입력 후 Enter

    Q43. 마커 라벨이 겹쳐서 안 보입니다.¶

    A. CMW2026은 SmartLabelStyle로 라벨 겹침을 자동 회피합니다. 그래도 겹치면 다음을 시도하세요.

    1. 마커 개수 줄이기: 불필요한 마커 삭제
    2. 그래프 확대: 마우스 휠 줌 또는 더블클릭 팝아웃
    3. Axis Control로 축 범위 조정: 라벨이 화면 밖으로 나가지 않도록

    Q44. 마커가 특정 주파수에 정확히 위치하지 않습니다.¶

    A. 마커는 가장 가까운 데이터 포인트로 자동 스냅됩니다. 데이터 포인트 간격(예: 0.5MHz)보다 세밀한 위치로는 이동할 수 없습니다.

    • NoP(Number of Points) 를 늘리면 (예: 1001 → 5001) 데이터 포인트가 촘촘해져 더 정밀하게 마커를 배치할 수 있습니다.
    • 또는 Add MK에서 원하는 주파수를 입력하면 가장 가까운 포인트에 자동 스냅됩니다.

    Q45. 마커 테이블에서 여러 마커를 한 번에 삭제하고 싶습니다.¶

    A. 다중 선택 후 Delete 키를 누릅니다.

    • Ctrl 키: 개별 추가 선택
    • Shift 키: 범위 선택
    • Ctrl+A: 전체 선택

    확인 대화상자에서 예를 클릭하면 일괄 삭제됩니다.

    Q46. 그래프를 확대했는데 원래대로 돌아가지 않습니다.¶

    A. 다음 방법으로 원래대로 복원합니다.

    1. ESC 또는 Space 키 → Axis Control 값으로 복귀
    2. 그래프 우클릭 → Axis Control 값으로 복귀
    3. Axis Control 테이블에서 직접 값 수정

    Q47. Compare (외부 s2p 오버레이) 파형을 보고 싶습니다.¶

    A. 다음 절차를 따르세요.

    1. Import → Import s2p 클릭 → s2p 파일 선택
    2. 그래프 상단의 Compare 체크박스가 자동으로 켜집니다.
    3. Compare S11/S21/S22가 점선으로 오버레이됩니다.
    4. Compare 마커를 추가하려면: 우클릭 → Add MK → Compare S11/S21/S22 선택
    5. Compare 마커를 삭제하려면: 우클릭 → Clear Compare Markers

    G. Temp Simulation¶

    Q48. Temp Simulation 값을 입력했는데 Temp 파형이 보이지 않습니다.¶

    A. 다음을 확인하세요.

    1. Δf 또는 ΔQu 값이 0이 아닌지 확인합니다. (0이면 Temp Sim 자동 OFF)
    2. Temp 체크박스가 켜져 있는지 확인합니다. (자동 전환되지만 수동으로 켜야 할 수 있음)
    3. Enter 키로 확정했는지 확인합니다.
    4. 로그에 "ApplyTempSimulation" 오류가 있는지 확인합니다.

    Q49. Orig과 Temp 파형을 동시에 보고 싶습니다.¶

    A. Orig과 Temp는 상호 배타적으로 동작합니다. 하나를 체크하면 다른 하나는 자동 해제되어, 두 파형을 그래프에서 동시에 볼 수 없습니다.

    대신 다음 방법으로 정량 비교하세요.

    1. Average Loss 테이블: Orig/Temp 각각의 손실을 기록하여 비교
    2. 마커 Meas 값: Orig/Temp 전환하며 마커의 Meas 값 비교
    3. Goals 마스크: Temp 파형이 마스크를 벗어나는지 확인

    Q50. Temp 파형이 Goals 마스크를 벗어납니다.¶

    A. 온도 마진이 부족하다는 의미입니다. 다음을 검토하세요.

    1. Δf를 줄임: 실제 온도 계수(TCF)를 재검토하여 Δf를 더 작게 설정
    2. ΔQu를 줄임: Qu 저하율을 보수적으로 설정
    3. N 증가: 선택도를 높여 마스크에 더 가깝게
    4. TZ 재배치: TZ가 마스크와 충돌하지 않도록 조정
    5. 설계 재검토: 극한 온도에서 규격 만족이 어려우면 재료 변경 고려

    Q51. Temp Simulation에서 마커가 이상한 값으로 표시됩니다.¶

    A. Temp Simulation 중 마커 Meas 값은 선형 보간(ReadYAtFreqInterpolated) 으로 계산됩니다. Temp 파형이 Δf만큼 이동해도 마커 주파수에서의 정확한 값을 얻을 수 있습니다.

    • 이상 값이 표시되면: 마커 주파수가 Temp 파형 범위를 벗어났을 수 있습니다.
    • 해결: 마커를 Temp 파형 범위 내로 이동하거나, Orig 상태로 전환하여 확인합니다.

    Q52. Temp Simulation 상태를 모드별로 관리하고 싶습니다.¶

    A. 자동으로 독립 관리됩니다.

    • Filter 모드: _tempShift_CBW, _tempQDegrade_CBW
    • Synthesize 모드: _tempShift_Synth, _tempQDegrade_Synth

    Filter 모드에서 Δf=+5를 입력한 뒤 Synthesize 모드로 전환하면, Synthesize 모드의 Δf는 별도로 관리됩니다(초기값 0). 다시 Filter 모드로 돌아오면 Δf=+5가 복원됩니다.

    H. 파일 입출력¶

    Q53. 저장한 CSV 파일을 열었더니 값이 다릅니다.¶

    A. 다음을 확인하세요.

    1. 파일 손상 여부: CSV 파일을 메모장으로 열어 섹션이 온전한지 확인
    2. 자동 마커: 자동 마커는 재계산되므로 수동 마커만 복원됩니다.
    3. TZ: Filter TZ는 자동 검출이므로 파일 로드 후 재검출됩니다.
    4. 매트릭스: [Target Matrix] 섹션이 온전한지 확인
    5. 로그에 Import 오류가 있는지 확인

    Q54. Export → Matrix로 저장한 파일을 다시 Import 했더니 Lock 상태가 사라졌습니다.¶

    A. Matrix Export는 Lock 상태를 함께 저장합니다. Import 시 Lock 상태도 복원됩니다. 다만 Lock 상태가 저장되지 않은 이전 버전 파일을 Import하면 Lock이 초기화됩니다. 파일을 다시 Export → Import 하면 Lock 상태가 유지됩니다.

    Q55. s2p Export 후 CST에서 열었더니 S11이 다릅니다.¶

    A. 다음을 확인하세요.

    1. CBW vs Synthesize: s2p Export 시 CBW 또는 Synthesize 중 선택합니다. 두 파형은 서로 다른 엔진에서 계산되므로 결과가 다를 수 있습니다.
    2. CST Mode: CMW2026은 CST 호환 모드가 항상 ON이므로 부호 규칙이 일치합니다.
    3. 주파수 단위: Export된 s2p는 MHz 단위입니다. CST에서 GHz로 표시되면 단위를 확인하세요.
    4. 포맷: Export된 s2p는 RI (Real-Imaginary) 포맷입니다. CST에서 동일하게 설정되어 있는지 확인하세요.

    Q56. 그래프 이미지 저장 시 정보 텍스트가 없습니다.¶

    A. Graph Image 저장 시 .png 와 .txt 두 파일이 함께 생성됩니다. .txt 파일이 없다면 저장 경로에 쓰기 권한이 없을 수 있습니다.

    • 해결: 다른 폴더(예: 바탕화면)에 저장해 보세요.
    • 로그에 "SaveGraphInfoAsText 오류" 메시지가 있는지 확인합니다.

    Q57. Import Mask 파일이 로드되지 않습니다.¶

    A. CSV 파일 형식을 확인하세요.

    1. 헤더: Type, F_Start, F_Stop 컬럼이 있는지 확인
    2. 숫자 형식: 1950.0 처럼 소수점 포함 (문자열 오류 방지)
    3. 빈 행: 빈 행은 무시됩니다.
    4. 로그: "ImportMask" 오류 메시지를 확인합니다.
    5. 샘플 CSV를 참고하여 형식을 맞춥니다.

    Q58. K-Inverter Export 값이 예상과 다릅니다.¶

    A. K-Inverter는 CBW를 임피던스 인버터(K) 값으로 변환합니다. 다음을 확인하세요.

    1. Fc, BW: 올바른 값이 입력되었는지 확인
    2. CBW_S2 / CBW_Ln1: 매트릭스 값이 유효한지 확인
    3. Z0: 기준 임피던스 (기본 50Ω)
    4. 로그: "K-Inv Export Error" 메시지 확인

    I. 성능 및 오류¶

    Q59. 프로그램이 자주 느려집니다.¶

    A. 다음을 시도하세요.

    1. NoP 낮추기: 1001 → 501 (S-파라미터 계산 포인트 수 감소)
    2. 마커 개수 줄이기: Clear All Manual Markers로 마커 정리
    3. Temp Simulation OFF: Δf/ΔQu를 0으로 설정
    4. GD 체크 해제: GD 계산은 추가 연산이 필요
    5. Auto Tuning 중지: 최적화 중에는 파형 갱신이 빈번
    6. 메모리 정리: 프로그램 재시작

    Q60. 프로그램이 크래시(Crash)됩니다.¶

    A. 다음을 확인하세요.

    1. 로그에서 마지막 ERROR 메시지 확인
    2. Windows 이벤트 뷰어 → 응용 프로그램 로그에서 오류 상세 확인
    3. 자주 발생하는 원인:
    4. 매트릭스 크기(N)가 예상 범위(2~20)를 벗어남
    5. TZ 값이 파형 범위를 벗어남
    6. s2p 파일 포맷 오류
    7. 기술 지원(donnylee@partron.co.kr) 으로 로그 + 상황 설명 전달

    Q61. "개체 참조가 개체의 인스턴스로 설정되지 않았습니다" 오류가 뜹니다.¶

    A. Null 참조 오류입니다. 다음을 확인하세요.

    1. 로그에서 어느 컨트롤이 Nothing인지 확인
    2. Form1_Load 초기화 실패 여부 확인
    3. 파일을 다시 로드하거나 Clear All 실행
    4. 반복되면 기술 지원에 문의

    Q62. Auto Tuning 중 프로그램이 멈춥니다(Freeze).¶

    A. Auto Tuning은 비동기(Task.Run) 로 실행되므로 UI가 멈추면 안 됩니다. 멈춘다면 다음 원인일 수 있습니다.

    1. Invoke 데드락: UI 갱신 Invoke가 완료되지 않음
    2. 무한 루프: _lastBestCost 갱신 실패로 Auto Restart가 무한 반복
    3. 메모리 부족: 대량 마커 + 반복 계산
    4. 해결: Stop 클릭 → 로그 확인 → 재시작

    Q63. 로그에 "Stack Overflow" 오류가 있습니다.¶

    A. 재귀 호출 깊이가 초과된 오류입니다. 다음을 확인하세요.

    1. 이벤트 재진입: CellValueChanged 핸들러에서 cell.Value = ... 대입 시 재귀 발생
    2. isUpdatingMatrix 플래그가 제대로 설정되어 있는지 확인
    3. 파일을 다시 로드하거나 Clear All 실행
    4. 반복되면 기술 지원에 문의

    J. 기타¶

    Q64. 단축키가 동작하지 않습니다.¶

    A. 다음을 확인하세요.

    1. Ctrl+S / Ctrl+O / Ctrl+Shift+G: 전역에서 동작
    2. Ctrl+Z / Ctrl+Y: 매트릭스 편집 중에만 동작
    3. ESC / Space: 그래프 영역 활성화 시 동작
    4. Delete: Marker Table, Goals Table 선택 후 동작
    5. Ctrl+C: Log 리스트박스 선택 후 동작

    일부 단축키는 컨텍스트(현재 활성 컨트롤) 에 따라 동작이 달라집니다.

    Q65. Clear All 후에도 이전 값이 남아있습니다.¶

    A. Clear All은 대부분의 데이터를 초기화하지만, 다음은 수동으로 초기화해야 할 수 있습니다.

    1. 파일 경로 (_currentFilePath): 수동 저장 경로가 유지됨 → 새 파일 저장 시 Save As
    2. Temp Simulation 상태: Δf/ΔQu를 0으로 수동 설정
    3. Axis Control: 기본값으로 리셋되지만, 수동 조정한 값이 남아있을 수 있음
    4. 로그: 수동으로 로그 지우기

    완전 초기화를 원하면 프로그램 재시작이 가장 확실합니다.

    Q66. 라이선스 파일(license.lic)을 갱신하고 싶습니다.¶

    A. 다음 절차를 따르세요.

    1. 기존 license.lic 백업 (다른 폴더로 이동)
    2. 새 license.lic 파일을 실행 폴더에 복사
    3. 프로그램 재시작
    4. About 창에서 라이선스 상태 확인

    라이선스 파일은 PC 하드웨어 핑거프린트 기반이므로, 다른 PC에서는 새로 발급받아야 합니다.

    Q67. 프로그램 업데이트는 어떻게 하나요?¶

    A. 현재 버전은 수동 업데이트 방식입니다.

    1. 기술 지원으로 최신 버전 요청
    2. 새 실행 파일(.exe)과 Resources/ 폴더를 덮어쓰기
    3. 기존 프로젝트 CSV 파일은 호환성 유지됩니다.
    4. license.lic 파일은 백업 후 복원 (재인증 필요할 수 있음)

    자동 업데이트는 향후 버전에서 지원될 예정입니다.

    Q68. 프로그램을 여러 개 동시에 실행할 수 있나요?¶

    A. 가능합니다. 다만 다음을 주의하세요.

    1. 메모리: 각 인스턴스가 메모리를 사용하므로, 대량 마커 + Auto Tuning 시 부족할 수 있음
    2. 파일 잠금: 동일한 CSV 파일을 동시에 저장하면 충돌
    3. 로그: 각 인스턴스의 로그는 독립적입니다.
