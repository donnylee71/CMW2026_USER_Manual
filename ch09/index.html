    1. 기본 개념 (Basic Concepts)¶

    Filter 필터
    특정 주파수 대역의 신호를 통과시키거나 차단하는 수동 소자 회로
    CMW2026은 Chebyshev 대역통과 필터(Band-Pass Filter)를 다룹니다. 필터는 통과대역(Pass Band)과 저지대역(Stop Band)을 구분하여 원하는 신호만 선택적으로 통과시킵니다.
    관련: Ch 1. 개요 Ch 4. Synthesize
    Band-Pass Filter BPF
    대역통과 필터
    특정 주파수 대역만 통과시키고 나머지는 차단하는 필터. 저역통과(LPF)와 고역통과(HPF)의 조합으로 구현됩니다. CMW2026의 주 대상입니다.
    관련: Ch 4 Ch 5
    Resonator 공진기
    공진기, 공진 회로
    특정 주파수에서 공진하는 소자. 필터는 N개의 공진기를 커플링으로 연결하여 구성됩니다. 캐비티, 유전체, 도파관, 모노블럭 등 다양한 형태가 있습니다.
    관련: Ch 5.2.1 매트릭스 구조
    Pole / Order (N) 차수
    필터 차수, 극점 수
    필터의 공진기 수. N이 클수록 선택도가 좋아지지만 삽입 손실과 크기가 증가합니다. CMW2026은 N=2~20까지 지원합니다.
    관련: Ch 3.3.1
    Pass Band
    통과대역
    필터가 신호를 통과시키는 주파수 대역. F_Start ~ F_Stop 사이. S21이 최대(0dB에 가까움)입니다.
    관련: Ch 5.3
    Stop Band
    저지대역
    필터가 신호를 차단하는 주파수 대역. S21이 최소(예: -40dB 이하)입니다.
    관련: Ch 5.3
    Insertion Loss IL
    삽입 손실
    필터를 삽입했을 때 통과대역에서 발생하는 신호 감쇠(dB). Qu(무부하 Q)와 FBW에 반비례합니다: `IL ≈ 1/(Qu · FBW)`.
    관련: Ch 5.7 Average Loss
    Return Loss RL
    반사 손실
    입력에서 반사되는 신호의 비율(dB). `RL = -20·log10(|S11|)`. 클수록 매칭이 좋습니다. 보통 15~25dB.
    관련: Ch 3.3.1
    Ripple
    리플
    통과대역 내 S11의 최대-최소 진폭 차이(dB). Chebyshev 필터의 특징. RL 값으로부터 유도됩니다.
    관련: Ch 4
    FBW (Fractional Bandwidth)
    분수 대역폭, 상대 대역폭
    `FBW = BW / Fc`. 대역폭을 중심 주파수로 나눈 비율. 필터 설계의 핵심 정규화 파라미터입니다.
    관련: Ch 5
    Chebyshev Filter
    체비쇼프 필터
    통과대역에 리플을 허용하는 대신 가파른 스커트 특성을 얻는 필터. 가장 널리 쓰이는 필터 타입. CMW2026의 기본 합성 방식입니다.
    관련: Ch 4 Ch 5
    Butterworth Filter
    버터워스 필터
    통과대역에 리플이 없는 최대 평탄(Maximally Flat) 필터. Chebyshev보다 스커트가 완만합니다.
    관련: Ch 4

    2. 커플링 매트릭스 (Coupling Matrix)¶

    Coupling Matrix
    커플링 매트릭스
    필터의 공진기 간 커플링을 행렬로 표현한 것. (N+2)×(N+2) 대칭 행렬. 대각선은 공진 주파수(Fi), 비대각은 커플링(CBW), Source/Load는 외부 Q(Qe)입니다.
    관련: Ch 5.2
    Coupling (M) M_ij
    커플링, 결합 계수
    공진기 i와 j 사이의 전자기적 결합 정도. CMW2026에서는 CBW(Coupling Bandwidth) 단위(MHz)로 표시됩니다.
    관련: Ch 5.2.2
    Main Coupling
    주 커플링
    인접한 공진기(i, i+1) 사이의 커플링. 매트릭스에서 대각선 바로 옆 셀(연녹색). 필터의 기본 대역폭을 결정합니다.
    관련: Ch 5.2.2
    Cross Coupling
    교차 커플링
    비인접 공진기(i, j, |i-j|≥2) 사이의 커플링. 매트릭스에서 대각선에서 먼 셀(흰색). TZ(전송 영점)를 생성합니다.
    관련: Ch 5.4
    CBW (Coupling Bandwidth)
    커플링 대역폭
    커플링 계수를 대역폭 단위(MHz)로 표현한 것. `CBW = M · BW`. CMW2026 매트릭스에 표시되는 값입니다.
    관련: Ch 5.2.2
    Fi (Resonant Frequency)
    공진 주파수
    각 공진기 i의 공진 주파수(MHz). 매트릭스 대각선 셀(노란색). 이상적으로는 모두 Fc와 같지만, 실제로는 미세 조정이 필요합니다.
    관련: Ch 5.2.2
    Qe (External Q)
    외부 Q
    Source/Load와 첫/마지막 공진기 사이의 결합 정도를 나타내는 Q. `Qe = BW·Fc / CBW²`로 CBW와 상호 변환됩니다.
    관련: Ch 5.2.2
    Qu (Unloaded Q)
    무부하 Q
    공진기 자체의 손실 특성. 재료와 구조에 따라 결정됩니다. 높을수록 삽입 손실이 낮습니다. 캐비티 5000~15000, 유전체 1000~5000, 모노블럭 500~2000.
    관련: Ch 3.3.1
    S1 / Ln (Source/Load Coupling)
    입출력 커플링
    Source(0)↔공진기1, 공진기N↔Load(N+1) 사이의 커플링. Qe로 표현됩니다.
    관련: Ch 5.2.2
    S2 / Ln-1
    Source/Load Cross Coupling
    Source↔공진기2, 공진기N-1↔Load 사이의 교차 커플링. 모노블럭 필터에서 자주 사용됩니다.
    관련: Ch 5
    S-L Direct Coupling
    S-L 직접 결합
    Source와 Load가 공진기를 거치지 않고 직접 결합하는 것. 매트릭스 (0, N+1) 셀.
    관련: Ch 5
    Lock / Unlock
    잠금 / 해제
    특정 매트릭스 셀을 Auto Tuning 중에도 변경되지 않도록 보호하는 기능. Lock된 셀은 엷은 주황색 배경.
    관련: Ch 5.2.4
    Ignore M_ij
    임계값 무시
    매트릭스 상단의 임계값(기본 0.001) 미만 커플링을 Auto Tuning에서 제외하는 기능. 회색 글자로 표시됩니다.
    관련: Ch 5.2.5
    CST Mode
    CST 호환 모드
    CST Microwave Studio의 부호 규칙을 따르는 모드. 현재 버전은 항상 ON입니다.
    관련: Ch 9

    3. S-파라미터 (S-Parameters)¶

    S-Parameter Scattering Parameter
    산란 파라미터
    고주파 회로의 입출력 특성을 나타내는 복소수 파라미터. `Sij`는 포트 j에서 입사, 포트 i에서 반사되는 신호의 비율입니다.
    관련: Ch 5.6
    S11
    입력 반사 계수
    입력 포트에서 반사되는 신호의 비율. `S11_dB = 20·log10(|S11|)`. 통과대역에서 -20dB 이하가 일반적입니다.
    관련: Ch 5.6.1
    S21
    순방향 투과 계수
    입력에서 출력으로 전달되는 신호의 비율. `S21_dB = 20·log10(|S21|)`. 통과대역에서 0dB에 가깝고 저지대역에서 낮습니다.
    관련: Ch 5.6.1
    S22
    출력 반사 계수
    출력 포트에서 반사되는 신호의 비율. 대부분의 대칭 필터에서 S22 ≈ S11입니다.
    관련: Ch 5.6.1
    S12
    역방향 투과 계수
    출력에서 입력으로 전달되는 신호. 수동 회로에서는 S12 = S21 (상호성).
    관련: Ch 5
    Magnitude |S|
    크기
    S-파라미터의 절대값. `|S| = sqrt(Re² + Im²)`. dB 변환의 기초입니다.
    관련: Ch 5
    Phase φ
    위상
    S-파라미터의 각도(라디안). `φ = atan2(Im, Re)`. Group Delay 계산의 기초입니다.
    관련: Ch 5
    dB (Decibel)
    데시벨
    비율의 로그 단위. 전력비 `dB = 10·log10(P2/P1)`, 전압비 `dB = 20·log10(V2/V1)`.
    관련: Ch 5

    4. TZ (Transmission Zero)¶

    TZ (Transmission Zero)
    전송 영점
    S21이 특정 주파수에서 급격히 떨어지는 지점(Notch). Cross-Coupling에 의해 생성되며, 가파른 스커트와 저지대역 감쇠를 제공합니다.
    관련: Ch 4.3 Ch 5.4
    Notch
    노치
    파형에서 V자 형태로 깊게 파이는 부분. TZ가 생성하는 S21의 국소 최소값입니다.
    관련: Ch 5.4.5
    TZ Depth
    TZ 깊이
    Notch의 깊이(dB). 주변 대비 얼마나 깊게 떨어지는지. CMW2026은 0.5dB 이상만 TZ로 검출합니다.
    관련: Ch 5.4.5
    Filter TZ
    필터 TZ
    Filter(CBW) 모드에서 파형으로부터 자동 검출된 TZ. 표시 전용(읽기 전용)이며 매트릭스와 직접 연동되지 않습니다.
    관련: Ch 5.4.4
    Synthesize TZ
    합성 TZ
    Synthesize 모드에서 사용자가 직접 입력/편집하는 TZ. 편집 가능하며, 파형 재계산에 직접 영향을 줍니다.
    관련: Ch 4.3.2
    TZ 드래그
    TZ 드래그
    Synthesize 모드에서 그래프의 TZ 세로 가이드선을 마우스로 잡아 좌우로 이동하는 기능. Filter 모드에서는 지원되지 않습니다.
    관련: Ch 4.3.3
    TZ 검출 (Detection)
    TZ 자동 검출
    파형에서 Notch를 자동으로 찾아내는 기능. 로컬 최소값, 최소 깊이(0.5dB), 최소 slope(0.3dB), 절대 레벨(-10dB) 조건을 만족해야 합니다.
    관련: Ch 5.4.5
    TZ 클러스터링 (Clustering)
    TZ 병합
    인접한 두 최소값이 하나의 TZ로 병합되는 것. FBW에 비례한 간격으로 병합됩니다.
    관련: Ch 5.4.5

    5. Group Delay (군지연)¶

    Group Delay GD
    군지연
    신호의 위상 지연을 주파수로 미분한 값. `GD = -dφ/dω`. 단위는 나노초(ns). 위상 왜곡의 지표입니다.
    관련: Ch 5.6.1
    GD11 / GD21 / GD22
    각 S-파라미터의 GD
    S11, S21, S22 각각의 Group Delay. 그래프 우측 보조 Y축에 표시됩니다. 색상: GD11=빨강, GD21=진초록, GD22=파랑.
    관련: Ch 5.6.1
    GD Flatness
    GD 평탄도
    통과대역 내 Group Delay의 평탄한 정도. 평탄할수록 위상 왜곡이 적습니다.
    관련: Ch 5
    GD Peak
    GD 피크
    필터 통과대역 가장자리에서 Group Delay가 급격히 증가하는 현상. 협대역 필터에서 두드러집니다.
    관련: Ch 5

    6. 최적화 (Optimization)¶

    Auto Tuning
    자동 튜닝
    최적화 알고리즘으로 매트릭스 값을 자동 조정하여 Goals를 만족시키는 기능. Filter 모드(매트릭스)와 Synthesize 모드(RL+TZ)에서 다르게 동작합니다.
    관련: Ch 5.5 Ch 4.4
    Optimization Goals
    최적화 목표
    Auto Tuning이 달성해야 할 마스크. Type(S11/S21/S22), Band(Pass/Stop), 주파수 범위, Target(dB), Weight로 구성됩니다.
    관련: Ch 5.3
    Cost (Cost Function)
    비용 함수
    최적화에서 최소화해야 할 목표 값. `Cost = Σ wᵢ · (위반량)²`. Threshold보다 작아지면 수렴으로 판정합니다.
    관련: Ch 5.5.3
    Threshold
    수렴 임계값
    Cost가 이 값보다 작아지면 Auto Tuning이 종료됩니다. 기본 0.001.
    관련: Ch 5.5.2
    Max Iter
    최대 반복 횟수
    Auto Tuning의 최대 반복 횟수. 입력값 × 1000. 기본 50(×1000=50,000회).
    관련: Ch 5.5.2
    Precision
    정밀도
    Cost 계산 포인트 수. 클수록 정밀하지만 느립니다. 기본 50.
    관련: Ch 5.5.2
    Tune Limit
    조정 한계
    초기값 대비 최대 조정 범위(%). 기본 30%. 이 범위를 벗어나면 초기값에서 멀어지지 않습니다.
    관련: Ch 5.5.2
    Simplex Nelder-Mead
    심플렉스 (넬더-미드)
    도함수 불필요 국소 최적화 알고리즘. N+1개 꼭짓점으로 구성된 심플렉스를 반사/확장/수축/축소하며 최적점을 찾습니다. Filter 모드 Auto Tuning의 기본 알고리즘입니다.
    관련: Ch 5.5.3
    Adam
    아담
    경사 기반 최적화 알고리즘. 1차 모멘텀(m)과 2차 모멘텀(v)을 결합. UI에 표시되나 현재 버전에서는 Simplex만 동작합니다.
    관련: Ch 5.5.3
    Adam+Jitter
    아담 + 지터
    Adam에 무작위 노이즈를 추가하여 Local Minima 탈출을 시도하는 변형. 현재 버전에서는 미사용.
    관련: Ch 5.5.3
    Resume
    재개
    Stop 후 현재 매트릭스에서 즉시 재시작. Start와 달리 초기값으로 리셋되지 않습니다.
    관련: Ch 5.5.5
    Auto Restart
    자동 재시작
    수렴 실패 시 Interval(s) 간격으로 자동 재시작하는 기능. 최대 10회.
    관련: Ch 5.5.5
    Interval (s)
    재시작 간격
    Auto Restart의 재시작 간격(초). 기본 5초. 최대 10회 재시작합니다.
    관련: Ch 5.5.5
    Stop (CTS Cancel)
    중단
    Auto Tuning 진행 중 즉시 중단. `CancellationTokenSource.Cancel()`을 호출합니다.
    관련: Ch 5.5.5
    RL/TZ Optimization
    RL/TZ 최적화
    Synthesize 모드 Auto Tuning. Coordinate Descent로 RL과 TZ를 교대로 최적화. Qu는 고정.
    관련: Ch 4.4.1

    7. 온도 시뮬레이션 (Temp Simulation)¶

    Temp Simulation
    온도 시뮬레이션
    온도 변화에 따른 필터 성능 변화를 시뮬레이션하는 기능. Δf와 ΔQu를 입력하여 Temp 파형을 생성합니다.
    관련: Ch 7. Temp Simulation
    Δf (Frequency Drift)
    주파수 이동량
    온도에 의한 중심 주파수 이동량(MHz). `Fi_new = Fi_orig + Δf`. 양수는 상향, 음수는 하향.
    관련: Ch 7.2.1
    ΔQu (Q Degradation)
    Q 저하율
    온도에 의한 무부하 Q 저하율(%). `Qu_new = Qu_orig × (1 + ΔQu/100)`. -10은 Qu가 90%로 감소.
    관련: Ch 7.2.2
    TCF (Temperature Coefficient of Frequency)
    주파수 온도 계수
    재료의 주파수 온도 의존성(ppm/°C). Temp Simulation에서는 사용자가 직접 Δf로 입력합니다.
    관련: Ch 7.2.3
    Orig
    원본 파형
    Temp Simulation과 대비되는 원래 파형. Temp Sim ON 시 Orig/Temp는 상호 배타적으로 표시됩니다.
    관련: Ch 7.3.3
    Temp 시리즈
    Temp 파형
    Temp Simulation 활성화 시 자동 생성되는 파형. 점선으로 표시됩니다. Temp S11/S21/S22, GD Temp S11/S21/S22.
    관련: Ch 7.3.4
    온도 마진 (Temperature Margin)
    온도 마진
    극한 온도에서 규격을 얼마나 여유 있게 만족하는지. Temp 파형이 Goals 마스크 내에 있으면 마진이 충분합니다.
    관련: Ch 7.7.1

    10. 수학 / 알고리즘 (Math & Algorithm)¶

    Golden Section Search
    황금 분할 탐색
    1차원 최적화 알고리즘. 황금비(0.618)로 구간을 축소하며 최솟값을 찾습니다. Synthesize 모드의 RL/TZ 최적화에 사용됩니다.
    관련: Ch 4.4.1
    Nelder-Mead Simplex
    넬더-미드 심플렉스
    도함수 불필요 국소 최적화. 반사(α=1), 확장(γ=2), 수축(ρ=0.5), 축소(σ=0.5) 연산 사용.
    관련: Ch 5.5.3
    Coordinate Descent
    교대 최적화
    여러 변수를 하나씩 교대로 최적화하는 방법. Synthesize 모드에서 RL → TZ → RL → ... 순으로 반복.
    관련: Ch 4.4.1
    Gaussian Elimination
    가우스 소거법
    연립방정식을 풀거나 역행렬을 구하는 알고리즘. Partial Pivoting으로 수치 안정성 확보.
    관련: Ch 5
    Partial Pivoting
    부분 피벗팅
    가우스 소거법에서 각 단계마다 가장 큰 피벗을 선택하여 행을 교환. 수치적 안정성 향상.
    관련: Ch 5
    LU Decomposition
    LU 분해
    행렬을 하삼각행렬(L)과 상삼각행렬(U)로 분해. 연립방정식 풀이에 사용.
    관련: Ch 5
    Local Minima
    국소 최솟값
    주변보다 작지만 전역 최솟값은 아닌 지점. Simplex가 갇힐 수 있어 Auto Restart로 탈출을 시도합니다.
    관련: Ch 5.5.5
    Early Stopping
    조기 종료
    일정 횟수(100회) 무개선 시 최적화를 조기 종료하는 기법.
    관련: Ch 5.5.3
    Best Cost 복원
    최적 상태 복원
    Auto Tuning 종료 시 가장 좋았던 매트릭스 상태로 복원하는 기능.
    관련: Ch 5.5.3

    11. 단위 / 기호 (Units & Symbols)¶

    MHz (Megahertz)
    메가헤르츠
    주파수 단위. 1 MHz = 10⁶ Hz. CMW2026의 기본 주파수 단위입니다.
    관련: Ch 3
    GHz (Gigahertz)
    기가헤르츠
    주파수 단위. 1 GHz = 10⁹ Hz = 1000 MHz. Touchstone 파일에서 자주 사용됩니다.
    관련: Ch 8
    dB (Decibel)
    데시벨
    비율의 로그 단위. S-파라미터, RL, 삽입 손실 등에 사용됩니다.
    관련: Ch 5
    ns (Nanosecond)
    나노초
    시간 단위. 1 ns = 10⁻⁹ s. Group Delay의 기본 단위입니다.
    관련: Ch 5.6.1
    Ω (Ohm)
    옴
    임피던스 단위. 시스템 기준 임피던스는 보통 50Ω.
    관련: Ch 8
    % (Percent)
    퍼센트
    백분율 단위. ΔQu, Tune Limit, Left Rate, Table Rate 등에 사용됩니다.
    관련: Ch 7
    ppm (Parts Per Million)
    백만분율
    10⁻⁶ 비율. TCF(온도 계수) 등에 사용됩니다.
    관련: Ch 7
    FBW (정규화)
    분수 대역폭
    `FBW = BW / Fc`. 무차원 비율. 정규화 주파수 `Ω = (f/Fc - Fc/f)/FBW`의 기초입니다.
    관련: Ch 5
    Ω (Normalized Frequency)
    정규화 주파수
    `Ω = (f/Fc - Fc/f)/FBW`. 실제 주파수를 정규화한 값. 매트릭스 방정식의 대각선 항에 사용됩니다.
    관련: Ch 5
